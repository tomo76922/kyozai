メニューは「まなぶ」「つたえる」「あそぶ」「つくる」の なかまに分けてあり、上のタブで切り替えられます
（くわしくは「[メニュー](#メニュー)」）。

ゲーム（ぴよぴよ ラン・たべもの キャッチ・よんもくならべ・リバーシ・しょうぎ）は、開くときに数字4けたのパスワードがいります（はじめは **0000**）。

## メニュー
トップページです。教材を なかまに分けて、タブで切り替えて表示します。

| タブ | 色 | 入っている教材 |
| --- | --- | --- |
| ぜんぶ | ちゃいろ | すべての教材 |
| まなぶ | あお | ひらがなカード・なぞりがき・かずあそび・けいさん・とけい・おかね・きせつクイズ・どっちかな |
| つたえる | オレンジ | きもちカード・よていボード・みえる タイマー |
| あそぶ | あか | ぴよぴよ ラン・たべもの キャッチ・しんけいすいじゃく・よんもくならべ・リバーシ・しょうぎ |
| つくる | みどり | ぬりえ・がっき・かざりつけ |

- タブの名前の下に、入っている教材の名前を小さく並べます。入りきらないときは、いくつかだけ出して「ほか3こ」のように残りの数を出します。
  タブの右上の数字は、入っている教材の数です
- 最後に選んだタブは この iPad に保存し、次に開いたときも同じタブになります
- 教材のボタンは、なかまの色にそろえています。絵と名前の下に、どんな教材かを短く書いています
- 声で操作できる教材には「こえ」、視線（目）で操作できる教材には「め」のしるしが付きます
  （こえ：ぴよぴよ ラン・たべもの キャッチ・どっちかな／め：たべもの キャッチ・ぬりえ・がっき・どっちかな）。パスワードがいるゲームには「パスワード」のしるしが付きます
- **よく つかう**：ボタンの右上の ★ を押すと「よく つかう」に入り、どのタブでも いちばん上に出ます。もう一度押すと外れます
- **この iPad に だす きょうざい**（先生用）：右上の「せってい」を長押しして開きます。教材ごとに「だす」「ださない」を選べ、
  「ださない」にした教材はメニュー（タブの中身・数を含む）に出ません。「ぜんぶ だす」で元に戻せます。
  中身が なくなった なかまのタブは かくれます
- タブ・★・だす きょうざい は、この iPad の中（ブラウザの保存領域）にだけ保存します
- iPad の横向き・縦向きのどちらでも、スクロールが少なくてすむように、ボタンの大きさと並びを画面に合わせて変えます
- プログラムは `menu.js`・`menu.css`。教材のボタンは `index.html` の `<a class="menu-item">`（なかまは `data-group` で決める）

## ひらがなカード
タップすると、その文字を読み上げるカードです。

- 五十音表の並び（5列）で大きなカードを表示
- 濁音・半濁音（が〜ぽ）25文字のカード
- 画面上のボタンで「あ〜ん」「が・ざ・だ・ば・ぱ」を切り替え
- 横向きでは五十音表と同じ縦の並び（右から あ行・か行…）になり、スクロールなしで全部見える
- タップで読み上げ（端末内の日本語音声を使用・外部サービスなし）
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## みえる タイマー
残り時間が色の部分の大きさで見えるタイマーです。

- 「1ぷん」「3ぷん」「5ふん」「10ぷん」で時間を選ぶ（最後に選んだ時間を覚えています）
- 円の色の部分が、時計の針と同じ向きに少しずつ減っていく
- 残りの分と秒も大きな数字で表示
- 「スタート」「とめる」「もどす」ボタン
- 時間になると、やさしいチャイム（ひかえめな音量）が2回鳴る。音はその場で作るので音のファイルは不要、オフラインでも鳴ります
- 動いている間は画面が暗くならないようにします（対応している iPad のみ。iPadOS 16.4 以降が目安）
- 縦向き・横向きどちらでもスクロールなしで使える

## きもちカード
気持ちや体の様子を、絵と言葉で伝えるカードです。

- 「きもち」：うれしい・たのしい・ふつう・かなしい・こわい・おこってる・さみしい
- 「からだ」：つかれた・ねむい・いたい・きもちわるい・さむい・あつい・のどがかわいた・おなかがすいた・トイレ
- 画面上のボタンで「きもち」「からだ」を切り替え
- 絵はページの中で描いているので、画像ファイルは不要。オフラインでも表示されます
- カードをタップすると、そのカードが画面いっぱいに大きく出て、言葉を読み上げます
  （先生や看護師さんに見せるときに）。もう一度タップすると一覧に戻ります
- 「ゆっくり」ボタンで読み上げ速度を遅くできる
- 横向きではスクロールなしで全部見える

## かずあそび
1から10までの数を、絵で数える教材です。

- 画面上のボタンで「かぞえる」「いくつかな」を切り替え
- 「かぞえる」：1〜10の数字をタップすると、その数だけいちごが1つずつ出てきて、
  「いち、に、さん…」と読み上げ、最後に「ぜんぶで さん」のように読み上げる（4は「よん」、7は「なな」）
- 「いくつかな」：いちご・ほし・はな・まるの絵の数を、下の数字ボタンから選ぶ。
  正解なら やさしい音と「せいかい」（読み上げも）、はなまる と キラキラが出て、少しあと（3秒。せっていで2〜5秒）に自動で次の問題へ。
  まちがいなら「もういちど」と出て、もう一度選べる。10問で一区切り（上に「3/10」と出る）（「もんだいの すすめかた」を見てください）
- 「1〜5」「1〜10」で問題の範囲を切り替え（最後に選んだ範囲を覚えています。切り替えると、あたらしい10問になります）
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると、正解のあと次の問題まで待つ時間（2〜5秒）を選べる
- 絵は5こずつ2段に並ぶので、5と10のまとまりが見えやすい
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げと数える速さを遅くできる

## とけい
アナログ時計の読み方を練習する教材です。

- 画面上のボタンで「うごかす」「なんじかな」を切り替え
- 「うごかす」：1〜12の数字が入った大きな時計。長い針（青）を指でぐるっと動かすと、
  短い針（赤）も本物の時計と同じように少しずつ動く（12をこえると次の時へ進む）。
  指をはなすと、その時刻を読み上げる（例：「さんじ じゅうごふん」）
- 時刻の文字（例：3じ15ふん）は「じこくを かくす」「じこくを みせる」ボタンで出したり隠したりできる
- 「なんじかな」：時計の時刻を、3つの答えから選ぶ。
  むずかしさは「ちょうど」「ちょうど・はん」「5ふんごと」「1ぷんごと」（最後に選んだものを覚えています）。
  正解なら やさしい音と「せいかい」（読み上げも）、はなまる と キラキラが出て、少しあと（3秒。せっていで2〜5秒）に自動で次の問題へ。
  まちがいなら「もういちど」と出て、もう一度選べる。10問で一区切り（上に「3/10」と出る）（「もんだいの すすめかた」を見てください）。
  むずかしさを切り替えると、あたらしい10問になります
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると、正解のあと次の問題まで待つ時間（2〜5秒）を選べる
- 読み方：じ は「よじ」「しちじ」「くじ」、ふん は「いっぷん・にふん・さんぷん・よんぷん・ごふん・
  ろっぷん・ななふん・はっぷん・きゅうふん・じゅっぷん」（15は「じゅうごふん」、20は「にじゅっぷん」）。
  30分は「さんじゅっぷん」と読み、「ちょうど・はん」のときだけ「はん」と表示・読み上げる
- 時計も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## よていボード
きょうの予定を、絵とひらがなのカードで上から順に並べるボードです。

- 子どもが見る画面：カードをタップすると言葉を読み上げ、「おわり」になって はなまるが付き、少しうすくなる。
  もう一度タップすると元に戻る（あわてて2回タップしたときは戻りません）
- まだ終わっていない一番上のカードが「いま」として大きく、色付きの枠で目立つ。ぜんぶ終わると「ぜんぶ おわったね」と出る
- 先生が並べる画面：右上の小さな「せってい」ボタンを **1秒ながおし** したときだけ開く（短く押すと「ながく おして ください」と出るだけ）
  - 用意されたカード（あさのかい・べんきょう・やすみじかん・おひるごはん・うんどう・あるく・おんがく・かんさつ・
    ぼっちゃ・ぎょうじ・おたのしみ・かえりのかい）から選んで、予定の最後に追加
  - 言葉を入力して自分のカードも作れる（12文字まで。絵は、最初の1文字を丸の中に書いたもの）
  - ▲▼で順番の入れかえ、「けす」でカードを消す
  - 時刻は入れても入れなくてもよい（入れるとカードに小さく表示。×で消せる）
  - 「はなまるを ぜんぶ けす」で、次の日のために印だけリセット
- 並べた予定は この iPad の中（ブラウザの保存領域）に自動で保存し、次に開いたときも残っています。外部には何も送りません
  （Safari の「履歴とWebサイトデータを消去」をすると消えます）
- はじめて開いたときは、れいとして5枚のカードが並んでいます
- 絵はページの中で描いているので、画像ファイルは不要。オフラインでも表示されます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## おかね
お金を数えたり、買いものやおつりを練習したりする教材です。

- お金の絵：1円・5円・10円・50円・100円・500円の硬貨と、1000円札。
  本物とまちがえないように、色・大きさ・金額の数字だけで区別するシンプルな絵です（本物の模様や肖像はなし。お札には「みほん」）。
  大きさは本物と同じじゅんばん（1円 ＜ 50円 ＜ 5円 ＜ 100円 ＜ 10円 ＜ 500円）で、少し差を大きくしています
- レベル（上の 1〜7 のボタンで選ぶ。まだひらいていないレベルはかぎのマーク）
  - レベル1：1円玉だけ（10円まで）
  - レベル2：10円玉と1円玉（100円まで）
  - レベル3：5円玉・50円玉も入る（100円まで）
  - レベル4：100円玉・500円玉も入る（1000円まで）
  - レベル5：1000円札も入る（2000円まで）
  - レベル6：かいもの（品物の絵とねだんを見て、下のお金をタップしてトレイに出す。トレイのお金はタップで戻せる。「これでいい」で答え合わせ）
  - レベル7：おつり（品物のねだんと出したお金を見て、おつりを数字ボタンで答える）
- レベル1〜5は「いくら？」：並んだお金の合計を答える。レベル1〜3は3つの答えから選び、レベル4・5は数字ボタンで入力（「けす」で1文字消す）。
  お金を1つずつタップすると、たした金額を「じゅう、にじゅう、にじゅうご…」と読み上げ、数えたお金はうすくなる（「かぞえなおす」で最初から）
- 正解なら やさしい音と「せいかい」（読み上げも）、はなまる と キラキラが出て、少しあと（3秒。せっていで2〜5秒）に自動で次の問題へ。
  まちがいなら「もういちど」と出て、もう一度答えられる。10問で一区切り（上に「3/10」と出る）（「もんだいの すすめかた」を見てください）
- 正解するたびに星が1つたまり、5つたまると「レベルアップ！」と出て やさしい音が鳴り、次のレベルがひらく。
  「レベル〇へ すすむ」「このまま」のどちらでも、10問のとちゅうなら そのまま続く（上のボタンや せっていで レベルを選びなおすと、あたらしい10問になります）。
  ひらいたレベルと星は この iPad の中（ブラウザの保存領域）に保存し、次も続きからできる。外部には何も送りません
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - まだひらいていないレベルも含めて、どのレベルでも選べる（各レベルの星の数も見られる）
  - 正解のあと次の問題まで待つ時間（2〜5秒）を選べる
  - 「きろくを リセット」を2回おすと、ひらいたレベルと星を消してレベル1に戻す
- 読み方：金額はひらがなで読み上げる（4円「よえん」、300円「さんびゃくえん」、600円「ろっぴゃくえん」、
  800円「はっぴゃくえん」、1000円「せんえん」など）
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## けいさん
ブロックの動きを見ながら、たしざん・ひきざんを練習する教材です。

- レベル（上の 1〜6 のボタンで選ぶ。まだひらいていないレベルはかぎのマーク）
  - レベル1：たしざん（こたえが5まで）
  - レベル2：たしざん（こたえが10まで）
  - レベル3：ひきざん（10までの数から）
  - レベル4：たしざんとひきざんのまぜた問題（10まで）
  - レベル5：くりあがりのあるたしざん（9＋4 など。こたえは11〜18）
  - レベル6：くりさがりのあるひきざん（13−5 など）
- 式（例：3 ＋ 2 ＝ ？）の下に、数の分だけブロックを並べる。式をタップすると読み上げる
  - たしざん：青と黄色の2つのかたまりが、くっついて1つになる
  - ひきざん：とるブロックが横にはずれて、うすい点線になる（「とる 2」と表示）
  - くりあがり：10個入りのわく（2だん×5れつ）を2つ使い、黄色のブロックが1つずつ青のわくへ移って10ができる（「10」と表示）
  - くりさがり：10のわくから、とる数だけブロックが1つずつはずれていく
  - 問題が出ると少しあとに動く。「うごきを みる」またはブロックをタップすると、もう一度動く
- 「ヒント」：ブロックを1つずつ光らせて、番号を付けながら「いち、に、さん…」と読み上げる（もう一度おすと止まる）
- 答えは下の数字ボタンで（レベル1は1〜5、レベル2〜4は1〜10、レベル5は10〜18、レベル6は1〜9）
- 正解なら やさしい音と「せいかい」、式と答えを読み上げる（例：「さん たす に は ご」）。
  はなまる と キラキラが出て、少しあと（3秒。せっていで2〜5秒）に自動で次の問題へ（次の式も読み上げる）。
  まちがいなら「もういちど」と出て、ブロックの動きをもう一度見せる。10問で一区切り（上に「3/10」と出る）（「もんだいの すすめかた」を見てください）
- 正解するたびに星が1つたまり、5つたまると「レベルアップ！」と出て次のレベルがひらく。
  「レベル〇へ すすむ」「このまま」のどちらでも、10問のとちゅうなら そのまま続く（上のボタンや せっていで レベルを選びなおすと、あたらしい10問になります）。
  ひらいたレベルと星は この iPad の中（ブラウザの保存領域）に保存。外部には何も送りません
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - まだひらいていないレベルも含めて、どのレベルでも選べる（各レベルの星の数も見られる）
  - 正解のあと次の問題まで待つ時間（2〜5秒）を選べる
  - 「きろくを リセット」を2回おすと、ひらいたレベルと星を消してレベル1に戻す
- ブロックも音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで、読み上げ・ブロックの動き・ヒントの数える速さを遅くできる

## きせつクイズ
季節の花・虫・行事・食べ物・歌を、絵を見て当てるクイズです。

- 画面の流れ：学年 → 季節 → ジャンル → クイズ。どの画面にも「もどる」ボタンがあります
  - 学年：小1〜小6・中学・高校。選んだ学年は この iPad の中に保存し、次に開いたときは その学年のまま季節を選ぶ画面から始まります
  - 季節：春・夏・秋・冬（問題が5問そろっていない季節は「じゅんびちゅう」と出て押せません）
  - ジャンル：花・虫・行事・食べ物・歌
- クイズ：大きな絵を見て「これは なに？」（歌は「これは なんの うた？」）に、3つの答えから選ぶ。
  まちがいの答えには、ほかの季節のものも かならず1つ入る
  - 問題が出ると、問題文と3つの答えを読み上げる（スピーカーのボタンで もう一度）

### 問題の足し方
問題は `kisetsu/data.js` に書きます。

- 1問は `{ name: '答え', pic: '絵' }`。
  - `name`：漢字の言葉は `[漢字:よみ]` と書く。1字ずつの読みを `.` で区切ると、習った漢字だけ漢字になる
    （例：`[入学式:にゅう.がく.しき]`）。区切らないと言葉全体で1つ（例：`[七夕:たなばた]`）。
    `[ ]` の外には漢字を書かない。学年ごとに別々に書く必要はありません
  - `pic`：絵文字（例：`'🍉'`、2〜3こ並べてもよい）か、`'svg:なまえ'`（同じファイルの `PICS` に描いた絵）
  - `pic` がない言葉は、ほかの季節の「まちがいの答え」だけに使われる
- その季節の5つのジャンルすべてに、`pic` のある問題が5問以上そろうと、自動で選べるようになります（問題は5問より多くてもよい。毎回その中から5問を選ぶ）
- 小学校で習わない常用漢字を使うときは、`kisetsu/kanji.js` の `JOYO_EXTRA` に足す
- 書きまちがい（`[ ]` の外の漢字、表にない漢字、読みの数のずれ）は、ブラウザのコンソールに出ます

## どっちかな
画面の左と右に絵（または写真）を大きく出し、どちらかを選ぶ教材です。特別支援学校の生活単元学習などで使うことを想定しています。

- 画面：上に問題文（例：「ふゆの ものは どっちかな？」）を出して読み上げる（スピーカーのボタンで もう一度）。
  左右の絵の下に、名前を小さく ひらがなで出す（「せってい」で消せる）。「ゆっくり」ボタンで読み上げを遅くできる
- 2つの使い方
  - **もんだい**（正解がある）：共通の部品 `shared/mondai.js` を使う。正解なら はなまる と「せいかい」、少しあと（3秒。せっていで2〜5秒）に自動で次へ。
    まちがいなら「もういちど」と言い、もう一度 問題を読んでから答えを待つ。10問で一区切り（なかまの問題が10問より少ないときは その数）。
    おわりの画面で「まちがえた もんだいを もういちど」ができる
  - **きもち**（正解がない）：どちらを選んでも「〇〇を えらんだね」と読み上げ、はなまるを出す。区切らずに続く（「もどる」で終わる）
- はじめから入っている問題（絵はページの中で描いたオリジナル。画像ファイルは使わない）
  - もんだい（30問）：きせつ6問・たべもの5問（あまい・からい・すっぱい・つめたい・あつい）・ふく5問・どうぐ6問（はを みがく・かみを とかす など）・
    てんき4問・あんぜん4問（わたって いい しんごう・とまる しんごう・あそんで いい ところ・さわると あぶない もの）。
    なかまを選ぶか「ぜんぶ まぜて」（30問から10問）。左右は毎回ばらばらで、正解が3回続けて同じ側には ならない
  - きもち（20問）：たべもの・あそび・のみもの・いろ・やりたい こと（ぬりえ／がっき、ひらがな／かず など）から2つずつ。なかまを選ぶか「ぜんぶ まぜて」
- 答え方（はじめの画面の「こたえかた」で選ぶ。最後に選んだものを覚えています）
  - **ゆびで**：左右のどちらかをタップ
  - **ことばで**：「みぎ」「ひだり」と言って答える。iPad（Safari）の音声認識を使うため、**インターネットが必要な場合があります**（画面にも書いています）。
    聞き取った言葉を画面の右下に出す。読み上げ中と直後に聞こえた言葉は使わない。
    この教材は声を保存しませんが、聞き取りのために iPad が声を Apple に送ることがあります（はじめて使うときに画面で説明します）
  - **こえで**（オフライン）：共通の部品 `shared/koe-switch.js` を使う。問題を読んだあと、左右が交互に光り、答えたい方が光ったときに声を出すと決まる。
    光る速さは「せってい」で 1.5・2・3・4・5秒から選ぶ。声の大きさの線は「こえテスト」で調整（ぴよぴよ ラン・たべもの キャッチと共通）
  - **めで**：共通の部品 `shared/shisen.js` を使う（はじめに カメラの説明と「あわせる」）。
    問題を読み終わってから10秒の間、左を見ていた時間と右を見ていた時間をそれぞれ合計する（まんなか・顔が見つからない時間は数えない）。
    10秒たったら長く見ていた方に決める。どちらも2秒未満、または差が1秒未満のときは決めずに「もういちど みてね」と言って、もう一度はかる。
    はかっている間は画面の下に残り時間の輪を出す
    - 「せってい」で選べること：はかる時間（5・8・10・12・15秒）、はじめの1秒を数えない（はじめは「かぞえない」）、
      左右どちらを見ているかを子どもに見せる／かくす（見せると影響されることがあるため、はじめは「かくす」）、判断に使うもの（め・かお・りょうほう）、しせんテスト
- **きろく**（先生用）：答えたこと（日時・セット・問題・左右の名前・選んだ方・正解か・答え方・めで のときは左右それぞれ見ていた秒数・ことばで のときは聞こえた言葉）を
  この iPad の中（ブラウザの保存領域）にだけ保存する。めで で決まらなかったときも「きまらず」として残る。名前（子どもの名前）は記録しない。
  「せってい」→「きろくを みる」で一覧（新しい順。画面には300件まで）、「CSV に かきだす」（Excel で文字化けしない形）、
  「ぜんぶ けす」（2回確認）。古いものから消して、3000件まで保存する
- **もんだいを つくる**（先生用）：「せってい」→「もんだいを つくる」
  - 「セット」に名前を付けて、問題をまとめる。セットごとに「もんだい（せいかい あり）」か「きもち（せいかい なし）」を選ぶ（1つのセットに まぜない）
  - 1問ずつ、左と右の写真（iPad のカメラで撮る・写真アプリから選ぶ）、問題文（読み上げもこの文で行う）、左右の名前（なくてもよい）、
    もんだい の セットでは正解（左・右）を入れる
  - 写真は長い辺を640ピクセルまでに小さくして保存する。セットは この iPad の中（ブラウザの保存領域 IndexedDB）にだけ保存し、外部には送らない。
    画面に「人の かおが うつった しゃしんは つかわないで ください」と出す
  - セットの並べかえ（▲▼）・なおす・けす（確認あり）。セットの中の問題も並べかえ・なおす・けすができる
  - 「かきだす」でセットをファイル（`.json`。写真も入る）にし、ほかの iPad の「ファイルから よみこむ」で読み込める（同じ名前があるときは「（2）」を付ける）
  - 作ったセットは はじめの画面の「せんせいが つくった もんだい」に出る。問題は作った順に出し、左右も作ったとおり
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く。正解のあと次の問題まで待つ時間は、ほかの教材（かずあそび・とけい など）と共通
- 音（正解の音など）と絵はページの中で作るので、ファイルは不要です。ことばで 以外はオフラインで動きます
- プログラムは `dotchi/`（`index.html`・`dotchi.css`・`dotchi.js`・問題 `data.js`・絵 `art.js`・もんだいを つくる `maker.js`）

## なぞりがき
ひらがな・カタカナ・すうじを、書き順どおりに指（Apple Pencil でも）でなぞる教材です。

- 画面上のボタンで「ひらがな」「カタカナ」「すうじ（0〜9）」を切り替え（最後に選んだものを覚えています）
- 一覧（ひらがな・カタカナは五十音表の並び。横向きでは右から あ行・か行…）から文字を選ぶと、なぞる画面になる
- なぞる画面
  - お手本の文字を、マスいっぱいに うすく大きく表示。いまなぞる画は少し色が付く
  - 書き順の番号と、書きはじめの位置に点を表示（いまなぞる画の点は赤くて、ゆっくり大きくなったり小さくなったりする）
  - 1画ずつ、正しい書き順でなぞれたら小さな「ポン」という音がして、次の画へ進む。
    多少はみ出しても、少し短くても大丈夫なくらい、判定はやさしめ（「ふとい」のときは さらに少しやさしい）
  - 書き順がちがったとき（例：2画目を先に書いた）、反対の向きに書いたとき、大きくはずれたときは、
    その画をそっと消して「もういちど」と表示（「1ばんから かこうね」「●の ほうから かこうね」「うすい せんを なぞってね」のどれか）
  - 全部なぞれたら、はなまると やさしい音（ひかえめな音量）。そのあと文字の読みを読み上げる
    （カタカナは ひらがなと同じ読み、「を」は「お」、すうじは「ぜろ・いち・に・さん・よん・ご・ろく・なな・はち・きゅう」）
  - 右（縦向きでは下）の大きな文字をタップすると、読みを読み上げる
  - 「おてほん」：書き順どおりに、1画ずつ線が書かれていくアニメーション（もう一度おすと止まる。なぞりはじめても止まる）
  - 「けす」：その文字をはじめからやり直す。「つぎ」：次の文字へ（最後の文字の次は最初の文字）。「いちらん」：文字の一覧に戻る
- 線の太さ：右上の「ふつう」「ふとい」から選ぶ（最後に選んだものを覚えています）
- Apple Pencil で書いているときは、画面に手のひらが当たっても線になりません
- なぞれた文字は、一覧で小さな赤い丸が付く（この iPad の中に保存。外部には何も送りません）
- 音はページの中で作るので、音のファイルは不要。書き順のデータもリポジトリに入れてあるので、オフラインで使えます

## しんけいすいじゃく
裏向きに ならべた カードを 2まいずつ めくって、同じ絵を さがす教材です。

- はじめの画面で むずかしさと あそぶ人を えらんで「はじめる」（最後に えらんだものを覚えています）
  - やさしい：16まい（8ペア）・4×4。オリジナルの どうぶつ8種類（うさぎ・くま・ねこ・いぬ・ぞう・ぱんだ・ひよこ・きつね）
  - ふつう：32まい（16ペア）・横向きは 8×4、縦向きは 4×8。栃木県の名物の食べもの16種類
    （いちご・ぎょうざ・かんぴょう・しもつかれ・ゆば・レモン牛乳・佐野ラーメン・耳うどん・ちたけそば・いもフライ・
    ポテト入り焼きそば・日光ようかん・たまり漬け・にら・とちぎ和牛・とうがらし）。絵の下に ひらがなで名前を小さく書く
  - むずかしい：64まい（32ペア）・8×8。トランプ2組を使い、52種類から ランダムに32種類をえらんで、同じマーク・同じ数字の2まいがペア。
    数字（A・2〜10・J・Q・K）とマーク（♠♥♦♣）を大きく、赤と黒で色分け。J・Q・K は数字の下に線
- どのむずかしさでも、画面の大きさ・向きに合わせてカードの大きさを変え、スクロールなしで おさまる（向きを変えると並べ直す）
- タップすると表になる。2まい めくって同じなら ペア成立（やさしい音と小さなキラキラ。カードは表のまま残り、ふちが金色になる）。
  ちがったら1秒後に裏に もどる（その間は ほかのカードを めくれない）
- 画面の上に「めくった かいすう」（2まい めくって1回）と「じかん」（1まいめを めくったときから数える）
- 全部そろったら、はなまると回数・時間を表示。「もういちど」「はじめの がめん」を えらべる
- きろく：ひとりで遊んだときの、むずかしさごとの いちばん少ない回数を この iPad の中（ブラウザの保存領域）に保存。
  はじめの画面の ボタンに「いちばん ○かい」と出る。記録を更新したら「しんきろく！」と表示
- ふたりで：交代で めくる（そろったら同じ人が もう一度めくれる。ちがったら交代）。画面の上に「ひとりめ」「ふたりめ」の
  そろえたペアの数と、どちらの ばんかを表示。そろえたカードのふちは その人の色（ピンク・青）。
  終わったら「○○の かち！」か「ひきわけ！」と出る。ふたりのときは記録は残さない
- 「おと」ボタンで音のオン・オフ（遊んでいる間は マークだけになる）
- ランキング：ひとりで遊ぶときは、はじめに なまえ（イニシャルと色のマーク）を選ぶ。全部そろえたら「きろくを おくる」で
  QRコードを出せる（「ランキング」を見てください）
- 「もくじ」ボタン：遊んでいる最中に押すと「やめる？」と出る（「つづける」「はじめの がめん」「やめる」）。その間と、
  ほかのアプリに切り替えている間は、時間を止める
- カードの裏は ほかの教材と同じ落ち着いた みどり。表は白地に太い ふちどりの絵で、はっきり見えるようにしている
- 絵（`art.js`）はすべてプログラムで描いた オリジナルで、既存のキャラクターや 実在の商品のパッケージ・ロゴは描いていない。
  音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

## よんもくならべ
たて6×よこ7の わくに コマを 落として、たて・よこ・ななめに 4つ ならべたら かちの ゲームです。開くときにパスワードがいります。

- はじめの画面で えらんで「はじめる」（最後に えらんだものを覚えています）
  - あそぶ ひと：「ひとりで（コンピュータと）」「ふたりで」
  - ひとりで のときは、コンピュータの つよさ（やさしい・ふつう・つよい）と、さきに おく ひと（じぶん・コンピュータ）もえらぶ。
    子どもは いつも あか、コンピュータは きいろ
  - ふたりで のときは、名前の かわりに色（あか・きいろ）で よぶ。あか から じゅんばんに おく
- わくの上の ▼（または その れつの どこでも）をタップすると、その れつの いちばん下まで コマが落ちる。
  コマは ▼の ところに 一しゅん 出てから 落ち、すこし はねて「ころん」と音がする。
  iPad の「視差効果を減らす」がオンでも 落ちる動きは出す（はねる動きだけ やめる）。いっぱいの れつは ▼が うすくなり、タップすると「そこは もう いっぱいだよ」
- 左（たてむきの ときは上）に、どちらの ばんかを大きく出す（「あなたの ばん」「コンピュータの ばん　かんがえちゅう…」「あかの ばん」など）。
  最後に おいた コマには 小さな白い しるしが付く
- 4つ ならんだら、そろった4つを光らせて（白い線で むすび、キラキラ）、ほかの コマは うすくする。
  「あなたの かち！」「あかの かち！」などと出し、「もういちど」「はじめの がめん」を えらべる。
  ばんが いっぱいに なったら「ひきわけ！」。はじめの画面に もどるまでの かった かずを下に出す（保存は しない）
- **まった**：1て もどす。ひとりで のときは、自分の手と そのあとの コンピュータの手を両方もどす（コンピュータが考えている とちゅうでも もどせる）。
  勝ち負けが ついたあとでも もどせる
- **ヒント**：おける ところ（それぞれの れつの いちばん下の あき）を うすく光らせ、よい手を ★で光らせる。
  「かてる ところ」「おかないと あいてが 4つ ならぶ ところ」「よさそうな ところ」を ことばでも出す。
  おくと すぐ上に あいてが おいて かってしまう ところには ✕ を付ける。もう一度押すと消える
- コンピュータの つよさ
  - やさしい：3回に1回くらいは てきとうに おき、ふだんも1手さきしか読まない（ときどき まちがえる）
  - ふつう：4手さきまで読む。たまに あまい手も ある
  - つよい：0.7秒くらいの間に、できるだけ先まで読む
- コンピュータの考え（`ai.js`）は すべて この iPad の中で計算する。外には何も送らないので、オフラインでも使える
- 「おと」ボタンで音のオン・オフ。音はページの中で作るので、音のファイルは不要
- 「もくじ」ボタン：遊んでいる とちゅうに押すと「やめる？」と出る（「つづける」「はじめの がめん」「やめる」）
- 保存するのは はじめの画面の えらんだものと 音の オン・オフだけで、この iPad の中（ブラウザの保存領域）に保存する
- 先生用：キーボードを つないでいるときは、数字の 1〜7 で れつを えらべる

## リバーシ

- はじめの画面で えらんで「はじめる」（最後に えらんだものを覚えています）

- おける ところには うすい まるが出る。そこを タップすると コマを おき（「ぱちっ」と音）、はさんだ コマが

- 左（たてむきの ときは上）に、どちらの ばんかと、いまの くろ・しろの かずを出す。最後に おいた コマには 小さな赤い しるしが付く

  パスの とちゅうでも もどせる）。勝ち負けが ついたあとでも もどせる
- **ヒント**：よい手を ★で光らせる。ほかの おける ところには、ひっくりかえせる かずを出す。

- コンピュータの つよさ
  - やさしい：3回に1回くらいは てきとうに おき、ふだんも たくさん ひっくりかえせる ところに おくだけ（さきは読まない）

- 「おと」ボタンで音のオン・オフ。音はページの中で作るので、音のファイルは不要

## しょうぎ
こまを うごかして、あいての おう（玉・王）を つかまえる（つみ）ゲームです。開くときにパスワードがいります。

- はじめの画面で えらんで「はじめる」（最後に えらんだものを覚えています）
  - あそぶ ひと：「ひとりで（コンピュータと）」「ふたりで（むかいあって）」
  - しゅるい：「ミニしょうぎ（5×5）」「ほんしょうぎ（9×9）」。
    ミニしょうぎは 昔からある 5五しょうぎの ならべかた（玉・金・銀・角・飛・歩 各1枚。下の だんに 左から 玉 金 銀 角 飛、玉の まえに 歩）
  - ひとりで のときは、コンピュータの つよさ（やさしい・ふつう・つよい）と、さきに さす ひと（じぶん・コンピュータ）もえらぶ。
    子どもの こまは いつも 下がわに出る（コンピュータが せんて のときは、ばんを まわして出す）
  - こまの よみがな：「つける」にすると、こまの 漢字の下に ひらがな（ぎん・ひしゃ など）を小さく出す
  - 「こまの うごきかた」ボタンは はじめの画面にもある
- こまを タップすると、うごける ところが みどりに光る（とれる こまには みどりの わ）。光った ところを タップすると うごく。
  もう一度 同じ こまを タップすると えらぶのを やめる
- とった こまは「もちごま」として ばんの よこ（たてむきの ときは 上と下）の こまだいに並ぶ（2枚いじょうは 数を出す）。
  もちごまを タップすると、うてる ところが光る
- なれる ところ（あいての じんち：ミニしょうぎは おくの 1だん、ほんしょうぎは 3だん）は ばんの いろを こくしてある。
  なれるときは「なる？」と聞き、なった こま と ならない こま の絵の ボタンで えらぶ。
  ならないと うごけなくなるとき（いちばん おくの 歩 など）は、聞かずに なる
- 王手のときは ばんに大きく「おうて！」と出し、おうの ますを赤く光らせる。つみに なったら「つみ！」と出し、
  「あなたの かち！」「せんての かち！」などと出す。「もういちど」「はじめの がめん」を えらべる。
  はじめの画面に もどるまでの かった かずを下に出す（保存は しない）
- 反則は できない：にふ・うちふづめ・うごけない ところへの こま打ち・おうが とられる ところへの うごき（王手を ほうっておく ことも）。
  ためそうとすると「おなじ たての れつに じぶんの ふが あるから うてないよ（にふ）」のように わけを出す
- おなじ かたち（こまの ならびと もちごまと 手番）が 4回 出たら「ひきわけ（せんにちて）」
- うごかしたあと、何をしたかを ことばで出す（「あいての 「かく」を とったよ」「コンピュータが 「ぎん」を うごかしたよ」など）
- **ふたりで**：iPad を ふたりの あいだに 平らに おいて、むかいあって あそぶ。下が せんて、上が ごて。
  ごての こま・もちごま、ごてに むけた ことば（「ごて：あなたの ばん」「おうて！ おうを まもろう」「かち！」）、
  ごてが こまを うごかすときの「なる？」、ごてが 王手されたときの「おうて！」は さかさまに出す。
  「こまの うごきかた」には「さかさまに する」ボタンがある
- **こまの うごきかた**：こまごとに、5×5の 図で うごける ところ（●は 1つ、矢じるしは どこまでも）と、
  なったときの うごきかたを ならべて出す。とりかた・もちごま・なる・王手・反則・せんにちて の きまりも ひらがなで書いてある
- **まった**：1て もどす。ひとりで のときは、自分の手と そのあとの コンピュータの手を両方もどす（コンピュータが考えている とちゅうでも もどせる）。
  勝ち負けが ついたあとでも もどせる
- **ヒント**：よい手を、うごかす こま（点線の わく）と うごかす先（★）で光らせ、「「ぎん」で ★の あいての 「かく」を とれるよ」
  「★に うごかすと つみ！」などと ことばでも出す。とられそうな じぶんの こまには 赤い わ と「!」を付ける。もう一度押すと消える
- コンピュータの つよさ
  - やさしい：1手さきだけ読み、わざと まよいを 入れる（ときどき まちがえる）
  - ふつう：3手さきまで読む（9×9では 1.2秒まで）。たまに あまい手も ある
  - つよい：1.3秒（5×5）・1.8秒（9×9）くらいの間に、できるだけ先まで読む
- ルールと コンピュータの考え（`rules.js`）は すべて この iPad の中で計算する。外には何も送らないので、オフラインでも使える。
  こまの 字は iPad に入っている 文字（明朝体）で書くので、フォントの ファイルは不要
- 「おと」ボタンで音のオン・オフ。音はページの中で作るので、音のファイルは不要
- 「もくじ」ボタン：遊んでいる とちゅうに押すと「やめる？」と出る（「つづける」「はじめの がめん」「やめる」）

## ぬりえ
線で区切られた絵を、色をえらんで ぬる教材です。指で ぬるほか、カメラで目の向きを読み取って「めで ぬる」こともできます。

- はじめの画面で テーマ と ぬりかた（「ゆびで ぬる」「めで ぬる（カメラ）」。最後に えらんだものを覚えています）を えらぶ
  - きせつ：はる（さくら・こいのぼり・チューリップ）／なつ（ひまわり・すいか・かきごおり）／
    あき（もみじ・どんぐり・おつきみ）／ふゆ（ゆきだるま・クリスマスツリー・かがみもち）
  - とちぎの たべもの：いちご・ぎょうざ・かんぴょう・レモンぎゅうにゅう・ゆば・ラーメン
  - キャラクター：しんけいすいじゃくの どうぶつ8種類（うさぎ・くま・ねこ・いぬ・ぞう・ぱんだ・ひよこ・きつね）と、
    ぴよぴよ ランの ひよこ（よこむき）
- 絵はすべてプログラムで描いた オリジナルの線画（`art.js`）。ぬる場所は大きめに区切っていて、1まいの絵で 3〜11か所。
  目や口などの こまかい線は ぬれない（上に かさねて描いてある）。実在の商品のパッケージ・ロゴは描いていない
- **ゆびで ぬる**：下の パレット（14色：あか・ピンク・だいだい・きいろ・きみどり・みどり・みずいろ・あお・むらさき・ちゃいろ・
  うすだいだい・はいいろ・くろ・しろ）で色をえらび、絵の場所をタップすると、その場所ぜんぶが その色になる（しろ で もとに もどせる）
  - 「もどす」：1つ前に もどす（何回でも）。「ぜんぶ けす」：確認してから ぜんぶ白に もどす（これも「もどす」で もとに もどせる）
- **めで ぬる（カメラ）**：共通の部品 `shared/shisen.js` を使う（「しせん」を見てください）
  - はじめに カメラを使う理由の説明 → 許可 → めの じゅんび（キャリブレーション。「まえと おなじ」で とばせる）
  - ぬれる場所が1つずつ順番に光る（オレンジの ふちで、ゆっくり点めつ）。まだ ぬっていない場所だけを順に光らせ、
    ぜんぶ ぬったら すべての場所を順に光らせる。うしろの背景は さいごに光る
  - **右を見る**と、いま光っている場所を いまの色で ぬる。ぬったあと 1.5びょう待ってから 次の場所が光り始める
  - **左を見る**と、色が順番に変わる（色の名前を読み上げる）。いまの色は 画面の左はしに 大きな丸で表示
  - 右・左を見つづけている間は、はしの 丸い わが たまっていく。たまったら きまる（ちらっと見ただけでは きまらない）。
    1回きまったら、まんなかを見るまで 次は きまらない。見つづけている間は 光る場所は 次に すすまない
  - 顔が見えないときは「かおが みえないよ」、暗いときは「へやを あかるくしてね」と出して止まる。指で タップしても ぬれる
- **できた！**：はなまると やさしい音（「できたね」と読み上げ）。絵は この iPad の中（ブラウザの保存領域）の「さくひん」に保存
  （同じ絵の「つづきを ぬる」で もう一度「できた！」を押すと、その さくひんを 上書き。さくひんは 120まいまで）
  - 「できた！」を押さずに「もどる」「もくじ」を押すと「やめる？」と確認する
- **さくひん**：はじめの画面の「さくひん」で、保存した絵を新しい順に見られる。タップで大きく表示し、
  「しゃしんに ほぞん」「つづきを ぬる」「けす」（確認あり）
- **しゃしんに ほぞん**：絵を 1200×1200 の画像（PNG）にして、iPad の「共有」を開く。「画像を保存」を えらぶと 写真アプリに入る。
  「共有」が使えないときは画像を大きく出すので、画像を長おしして「"写真"に保存」を えらぶ
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く（ぬっている間は かくれる）
  - めで ぬる：ひかる はやさ（はやい 1.5びょう・ふつう 2.5びょう・ゆっくり 4びょう・とても ゆっくり 6びょう。はじめは ふつう）
  - めで ぬる：みつづける じかん（0.5〜1.5びょう）・はんだんに つかう もの（め・かお・りょうほう）・しせんテスト・めの じゅんびで 1つの まるを みる じかん（5・8・12びょう）
    （この2つは しせんの共通の せっていで、たべもの キャッチと同じ）
  - おと：あり・なし
- 保存するのは ぬった色と日付・せっていだけで、名前や写真は保存しない。カメラの映像は保存も送信もしない。外部には何も送りません
  （Safari の「履歴とWebサイトデータを消去」をすると さくひんも消えます。残したい絵は「しゃしんに ほぞん」してください）
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます（めで ぬる は、カメラの部品を一度 読み込んだあと）

  「共有」が使えないときは画像を大きく出すので、画像を長おしして「"写真"に保存」を えらぶ
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く（かざっている間は かくれる）
  - おと：あり・なし（シールを はる・できた！ などの音。はじめは あり）
- 保存するのは 場面・シールの いちと大きさ・日付・せっていだけで、名前や写真は保存しない。外部には何も送りません
  （Safari の「履歴とWebサイトデータを消去」をすると さくひんも消えます。残したい かざりつけは「しゃしんに ほぞん」してください）
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

## がっき
がっきを 鳴らして、院内学級の みんなで 1人1台の iPad を使って えんそうかいを する教材です。

- がっきは ピアノ・もっきん・たいこ・すず・カスタネット・トライアングル の6つ。音はすべてページの中で作るので、音のファイルは不要。オフラインでも鳴ります
- 音量はひかえめ。右上の「おと」ボタンで「ちいさい・ふつう・おおきい」を切り替え（この iPad に保存）。
  対応している iPad では、消音モード（サイレント）でも がっきの音が鳴ります
- はじめに「ゆびで」か「めで（カメラ）」を選ぶ

### がっきを えらぶ
- がっきは 1つか 2つ 選べる（選んだ順に 1・2 の番号が出る）。3つめを選ぶと「2つ まで だよ」と出る
- ゆびで：がっきの大きなボタンをタップして選び、「けってい」で次へ
- めで：視線の共通部品（`shared/shisen.js`）を使う（カメラの説明 → 許可 → めの じゅんび。めの じゅんびで 1つの丸を見る時間は「せってい」で 5・8・12びょう）。
  がっきが1つずつ順番に光り（そのがっきの音も小さく鳴る）、**右**を見ると光っているがっきを選ぶ（もう一度 右を見ると はずす）。
  **左**を見ると「けってい」。見ている間は わが たまっていく。先生が指でタップして選ぶこともできます
- 前に選んだがっきを覚えています

### じゅんび（先生が えらぶ）
- **ゆびで えんそうの しかた**（ゆびで のときだけ）：「じゆうに ひく」「おとゲーム」（おとゲームは 曲と むずかしさを選ぶ。くわしくは「ゆびで おとゲーム」）
- **めで えんそうの しかた**（めで のときだけ）：「じゆう」「リズム」
- **みつづけた ときに おとが かわる はやさ**（めで じゆう のときだけ）：「ゆっくり（2びょう）」「ふつう（1びょう）」「はやい（0.5びょう）」
- **ひかる はやさ**（めで リズム）：「とても ゆっくり（4びょうに 1かい）」「ゆっくり（3びょうに 1かい）」「ふつう（2びょうに 1かい）」。
  「せってい」で 1.5〜8びょうの間を 0.5びょうずつ 細かく変えられる
- **きょく**：「きょく なし」「きょく あり」
- きょく あり：「きらきらぼし」「かえるの うた」「ちょうちょう」「メリーさんの ひつじ」の メロディ（歌詞なし。ひくい音の伴奏つき）を流す
  - 「2はくに 1かい」「4はくに 1かい」光るかを選ぶ。**曲の速さは、光る間かくと この はく数から自動で決まる**
    （例：2びょうに 1かい・2はく → 1ぷんに 60はく、3びょうに 1かい・4はく → 1ぷんに 80はく）。
    そのため、子どもの iPad（きょく なし・同じ はやさ）と光る間かくが かならず そろいます。
    曲が遅すぎる・速すぎる組み合わせ（1ぷんに 45はく未満・132はく より上）は選べません
  - 流す回数：「1かい」「2かい」「3かい」「ずっと」。終わると光るのも止まり「おしまい！」と出る
  - 曲は **先生の iPad 1台だけ** で流し、子どもの iPad は「きょく なし」で 同じ はやさにして使う想定です
- 選んだ内容は この iPad に保存します
- 「ゆびで」のときも「きょく あり」を選べる（曲が流れ、子どもは自由にタップ。光る合図は出ない）

### ゆびで えんそう
- 選んだがっきを 大きなボタンで出し、タップすると音が鳴る（何本の指でも同時に鳴る）。2つ選んだときは左右に並ぶ
- ピアノ・もっきんは、ドから次のドまでの8音を、音ごとに色分けした大きな けんばんで出す（ド・レ・ミ… の名前つき）。もっきんは 高いほど短い板
- たいこ・すず・カスタネット・トライアングルは、大きなボタンで1つめの音（ドン・シャン・タン・チーン）、下の小さめのボタンで2つめの音（カッ・シャラシャラ・タタン・チリリリ）
- 「きょく なし」のときは、すぐに自由に鳴らせる（スタートは なし）

### ゆびで おとゲーム
曲に あわせて 丸が おりてきて、「ここで タップ」の線に来たときに たたくゲームです。

- じゅんびの画面で「じゆうに ひく」「おとゲーム」を選ぶ（この iPad に保存）。おとゲームでは 曲（きらきらぼし・かえるの うた・ちょうちょう・メリーさんの ひつじ。歌詞なし）と むずかしさを選ぶ
- がっきを2つ選んだときは、1つめのがっきで あそぶ
- **ピアノ・もっきん**：下に ドから上のドまでの8つの けんばんを 色分けして並べ（ド・レ・ミ… の名前つき）、その真上が 丸の通り道（レーン）。
  曲の音にあわせて、名前が書かれた 同じ色の丸が その音の けんばんの上から おりてくる
- **すず・トライアングル・カスタネット**：レーンは1本。曲のリズムに あわせて 丸が おりてくる。下の大きなボタンを たたく
- **たいこ**：「ドン」「カッ」の2本のレーン（はくの頭は ドン、そのほかは カッ）
- 次に たたく けんばん・ボタンは 光って少し大きくなる。丸の大きさは、丸どうしが かさならないように 自動で 変わる（56px より小さくは しない）
- 判定は やさしめ：線にぴったりなら「ぴったり！」、少しずれたら「いいね！」、大きくずれたら「おしい！」。失敗という ことばは使わない。
  とおりすぎた丸は うすくなるだけ。ちがう けんばんを たたいたときは、音は鳴るが 判定には入れない
- メロディは 子どもが たたいた音で鳴る。うしろで 伴奏（ひくい音・和音・シャッという リズム）を 小さく流す
- むずかしさ：

| むずかしさ | 曲の速さ | 丸 | 判定の はば（ぴったり／いいね／おしい） |
| --- | --- | --- | --- |
| れんしゅう | 1ぷんに 66はく | 曲の音 ぜんぶ。丸が線に来たら、正しい けんばんを たたくまで 曲も伴奏も止まって まつ（「たたいてね」） | ±0.2／0.42／0.75びょう |
| やさしい | 1ぷんに 66はく | 2はく以上 あいだを あけて、同時に 見える丸は 1つだけ | ±0.23／0.47／0.8びょう |
| ふつう | 1ぷんに 84はく | 曲の音 ぜんぶ（丸が多い） | ±0.14／0.3／0.55びょう |

- 曲の速さは「せってい」の「おとゲーム：きょくの はやさ」で、いつもの 50〜150% に 10% ずつ 変えられる
- 「スタート」で 3、2、1 のあと始まる（丸は カウントダウンの あいだから おりてくる）。「とめる」「もういちど」も使える
- 曲が終わると「おしまい！」と はなまる、ぴったり・いいね・おしい の かずを出す
- プログラムは `gakki/otogame.js`。曲は「曲を ふやす・直すとき」と同じ `SONGS` を使うので、曲を足すと おとゲームにも出る

### めで えんそう
じゅんびの画面で、先生が「じゆう」か「リズム」を選びます（この iPad に保存）。

#### じゆう
- 光る合図は なし。画面を左右に分け、**左を見ると左のがっき、右を見ると右のがっき**が鳴る。まんなかを見ているときは 鳴らない（お休み）
  - がっきを2つ選んだとき：左が1つめ、右が2つめ。1つのとき：左右とも同じがっき
- 左か右を見て、見つめる時間（リズムと同じ設定。はじめは 0.3びょう）がたつと 1つめの音が鳴る
- そのまま見つづけると、一定の間かくごとに 次の音が鳴り、音が だんだん変わる
  - ピアノ・もっきん：ド→レ→ミ→ファ→ソ→ラ→シ→ド と上がり、上のドまで行ったら ド→シ→ラ… と下がって、また上がる
  - すず・トライアングル：高さを少しずつ変えた音を順番に（5だんの 高さを 上がって 下がる）
  - たいこ：ドン→ドン→カッ をくりかえす
  - カスタネット：大きい音と小さい音を交互に
- 左右それぞれ、いま鳴っている音を大きく表示する。ピアノ・もっきんは 下の小さな けんばんの その音の色が光り、すず・トライアングルは 高さの だんが光る。
  見ている間は わが たまっていき、いっぱいになると 次の音
- 次の音に変わる間かくは、じゅんびの画面で「ゆっくり（2びょう）」「ふつう（1びょう）」「はやい（0.5びょう）」から選ぶ（この iPad に保存）
- まんなかを見てから もう一度 同じ方向を見たときは、はじめの音（ド など）から。「せってい」で「つづきから」にも変えられる
- 指で左右をタップしても、次の音が鳴る
- 「きょく あり」も選べる（ゆびでと同じく、スタートの あと曲が流れ、そのあいだ 自由に鳴らす）

#### リズム
- 画面を左右に分け、決まった速さで 左 → 右 → 左 … と交互に光る（光ったほうに「みて！」）
- 光ったほうを見つづけると、その音が1回鳴る。**光るのに少し遅れて見ても、次が光るまでの間に見れば鳴る**（失敗にはしない）
- 見つめる時間は ふつうより短い **0.3びょう**（視線の判定に時間がかかるため）。「せってい」で 0.1〜0.8びょうに変えられる
- 左右の音：
  - がっきを2つ選んだとき：左が1つめ、右が2つめのがっき
  - 1つ選んだとき：左右で音を変える（ピアノ・もっきん：左「ド」右「ソ」／たいこ：左「ドン」右「カッ」／すず：左「シャン」右「シャラシャラ」／
    カスタネット：左「タン」右「タタン」／トライアングル：左「チーン」右「チリリリ」）
- いま見ているほうに「みてるよ」と出る（先生が判定を たしかめられる）。左右を指でタップしても鳴る
- 顔が見えないときは「かおが みえないよ」などと出る。みんなと そろえるため、光るのは止めずに続ける

### みんなで そろえて はじめる
- 「スタート」を押すと「3、2、1」と大きな数字と「ピッ」という音でカウントダウンしてから始まる。先生の「せーの」に合わせて全員が同時に押す
- とちゅうで「とめる」（スタートの前に もどる）・「もういちど」（すぐに 3、2、1 から やり直す）ができる
- えんそう中は、画面が暗くならないようにします（対応している iPad のみ）
- 「もくじ」「もどる」を えんそうの画面で押したときは「やめる？」と確認する

### せってい（先生用）
右上の「せってい」を長押しすると開きます（えんそう中は かくれます）。
おとゲームの 曲の はやさ（いつもの 50〜150%）、めで リズムの ひかる はやさ（細かく）、めで えんそうの 見つめる時間（じゆう・リズム 共通）、
めで じゆうで もう一度 同じ方向を見たとき（はじめの おとから／つづきから）、めで がっきを えらぶときの 光る時間（2〜6びょう）・見つめる時間、
判定に使うもの（め・かお・りょうほう。ほかの教材と共通）、しせんテスト。

### 曲を ふやす・直すとき
曲は `gakki/oto.js` の `SONGS` に書いてあります。`melody` は「音の名前＋長さ（はく。1はくなら書かない）」をスペースで区切って書きます
（例：`ソ2` はソを2はく、`ド.5` はドを半ぱく、`-` は 1はく休み、高いドは `ド^`）。`bass` は 2はくごとの低い音（ド・ファ・ソ）です。
曲の長さ（はく数）は 4の倍数にし、`bass` の数は はく数の半分にしてください。

## ぴよぴよ ラン
ひよこが右へ自動で走る、横スクロールのゲームです。開くときにパスワードがいります。

- はじめの画面で、ステージ・あそびかた・むずかしさを選ぶ（あそびかたと むずかしさは この iPad に保存し、次も同じ）
- **ゆびで あそぶ**：画面のどこかをタップするとジャンプ（少し早めにタップしても、着地したらすぐ跳びます）
- **こえで あそぶ**：声を出すとジャンプ。共通の部品 `shared/koe-switch.js` を使い、声の大きさだけで判定する
  （音声認識はしない・録音しない・オフラインで動く）。指でタップしてもジャンプできます
  - はねを取っているときは、空中でもう一度 声を出すと2段ジャンプ
  - 声がのびて何度もジャンプしないように、1回ジャンプしたら0.4秒は次の声に反応しない
    （「せってい」で 0.3・0.4・0.6・0.8・1びょう から選べる。この待ち時間は この ゲームだけの設定）。
    声がいったん小さくなるまでも反応しません
  - はじめの画面の「こえテスト」で、声の大きさのメーターと反応する線を見ながら、反応する大きさ（しきい値）を変えられる。
    しきい値は「たべもの キャッチ」と同じ設定（共通の保存）を使う
  - はじめて使うときは、マイクを使う理由を やさしく表示してから、iPad の許可をたずねる
  - 遊んでいる間は、画面の下に声の大きさのメーターが出る
- アイテム
  - どんぐり：道や空中に並んでいて、取ると右上の数がふえる。ジャンプして取る高い位置に どんぐりがあるときは、
    その真下の地面には置かない（跳ぶかどうか迷わないように）
  - はね：取ると10秒の間、空中でもう1回ジャンプできる。はねが続いている間に通る場所に、2段ジャンプでないと届かない
    高いどんぐりを置く（ふつうのジャンプで届くのは地面から約230まで。高いどんぐりは290〜305の高さ）
  - ほし：取ると8秒の間キラキラ光り、障害物にぶつかっても平気
  - パワーアップ中は、画面の右はしに残り時間がバーで出る（残りが少なくなると、やさしく点滅）
- 障害物：低い石・池（こい青で、ふちに明るい線）・高い切り株
- ステージ1〜5（のはら・おはなばたけ・もりの みち・かわべ・ゆうやけ）。始まるときに「ステージ3」のように大きく表示。
  1ステージは「ふつう」で約55秒。ならびは毎回同じ。ステージが進むほど、少しずつ はっきり むずかしくなる

  | | ステージ1 | 2 | 3 | 4 | 5 |
  | --- | --- | --- | --- | --- | --- |
  | 走る速さ（ステージ1を1） | 1 | 1.1 | 1.21 | 1.33 | 1.46 |
  | 障害物の数（ふつう） | 12 | 16 | 20 | 25 | 30 |
  | 障害物の種類 | 低い石だけ | ＋池 | ＋高い切り株 | ＋2つ続けて来る | 全部が混ざる（2つ続けても多め） |
  | 池の幅 | − | 64 | 74 | 84 | 94 |
  | はね・ほし | 2・2 | 2・1 | 1・1 | 1・1 | 1・0 |

- むずかしさ（どれでも、ステージが進むほど むずかしくなる しくみは同じ）
  - **やさしい**：全体がゆっくり（約0.75倍）。障害物は少なめ（約0.75倍）。ぶつかっても少し前に戻ってやり直す
  - **ふつう**：ぶつかっても少し前に戻ってやり直す
  - **むずかしい**：速さ約1.1倍、障害物 約1.2倍。画面の上にハート3つの体力ゲージが出て、ぶつかるたびに1つ減る。
    3回ぶつかると「おしまい」（それまでの どんぐりの数と「もういちど」「もくじ」）。ほしを取っている間は減らない
- ぶつかったとき：「おっとっと」と出て、やさしい「ぽよん」という音のあと、ふわっと うすくなって戻る
  - 戻る場所は、ぶつかった障害物の **1つ前の障害物より さらに手前**（助走できるように、約1.3秒ぶん手前。
    その また前の障害物には かからない場所）。むずかしいでも同じ
  - 戻ったら **0.5秒 止まってから** 走り出す（心の準備）。戻ってから **2秒間** ひよこが点滅し、その間はぶつかっても平気
  - 同じ障害物に **3回続けて** ぶつかったら、次から その障害物の手前で「いま！」と大きく表示し、
    読み上げて（iPad の中の日本語の声）ジャンプのタイミングを教える。その障害物を こえられたら おしまい。
    やさしい・ふつうだけ（むずかしいでは出さない）
- ゴールすると、はなまると取ったどんぐりの数を表示。「つぎの ステージ」「もういちど」「ステージを えらぶ」
- ランキング：はじめに なまえ（イニシャルと色のマーク）を選ぶ。ゴールしたら「きろくを おくる」で QRコードを出せる
  （「ランキング」を見てください）
- クリアしたステージは この iPad の中（ブラウザの保存領域）に保存し、ステージ選びの画面で次のステージがひらく
  （クリアしたステージには はなまると、いちばん多く取ったどんぐりの数）。外部には何も送りません
- 音：ジャンプ・どんぐり・パワーアップ・ゴールの効果音（ひかえめな音量）。「おと」ボタンでオン・オフ。
  こえで あそぶ ときは、効果音や「いま」の読み上げをマイクが拾ってジャンプしないように、少しの間は声に反応しない
- きょく（BGM）：ステージごとに オリジナルの曲。既存の曲は使わず、すべてプログラムの中で作曲・演奏する（音のファイルなし・オフラインで鳴る）
  - ステージ1：明るく のんびりした森の曲／2：はずむような草原の曲／3：少し元気な川べりの曲／
    4：わくわくする夕方の曲／5：盛り上がるゴール前の曲
  - テンポはステージが進むほど少し速い（92・104・112・120・132）
  - ほしでパワーアップしている間は、高いキラキラの音とリズムが加わって にぎやかになる
  - ゴールすると短いファンファーレ。一時停止中は止まり、続けると止めたところから鳴る
  - 「きょく」ボタンでオン・オフ（「おと」とは別）。音量は「せってい」で効果音と別々に4段階
  - **こえで あそぶ ときは、はじめから きょくなし**（曲の音をマイクが拾ってジャンプしないように）。
    先生が「せってい」で オンにできる（そのときは「きょく」ボタンは出ません）
- マイク：こえで あそぶ ときは、エコーキャンセル（スピーカーから出た音を消して聞く機能）を有効にして音を拾う
  （共通の部品 `shared/koe-switch.js` の設定）
- 「もくじ」ボタン：遊んでいる最中に押すと一時停止して「やめる？」と出る（「つづける」「ステージを えらぶ」「やめる」）。
  ほかのアプリに切り替えたときや、縦向きにしたときも一時停止します
- 先生用：ステージ選びの画面の右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - 「こえで あそぶ」：ジャンプの待ち時間・いまの しきい値・こえテスト
  - 「おと」：効果音と きょくの 音量（それぞれ4段階）、こえで あそぶ ときに きょくを ならすか
  - 「ぜんぶの ステージを ひらく」：クリアしていないステージも選べる（もう一度押すと元に戻す）
  - 「きろくを けす」を2回おすと、クリアの記録とどんぐりの数を消す
- iPad の横向きで画面いっぱいに表示。縦向きのときは「よこに してね」と表示します
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

## たべもの キャッチ
上から落ちてくる食べものを、かごを持ったひよこを左右に動かしてキャッチするゲームです。開くときにパスワードがいります。

- 操作：画面を指で左右になぞると、ひよこが指についてくる。左右の下のすみの「＜」「＞」ボタン（おしている間 動く）でも動かせる
- 落ちてくるもの（でてくる回数は、得点が高いものほど少ない）
  - チーズ 10てん・かんぴょう 20てん・ラーメン 30てん・ぎょうざ 40てん・いちご 50てん
  - ハート：体力が1つ回復（体力がへっているときだけ、たまに出る）
  - かみなり・いわ・さる：キャッチすると体力が1つへる
  - 絵は絵文字。かんぴょうは合う絵文字がないので、干したかんぴょうの束（クリーム色の帯を束ねて ひもで しばった形）を
    プログラムで描き、下に小さく「かんぴょう」と書く
  - 見やすさ：落ちてくる物は、白くて太い ふちどりの丸の上にのせて目立たせる。体力がへるものは、ふちどりを こい灰色にして
    見分けやすくする。背景は、落ちてくる物が目立つように、少し暗めの落ち着いた色。落ちるときは ほぼ まっすぐ（文字が さかさに ならない）
  - 落ちる場所の地面に かげが出るので、どこに落ちるか分かる
- 体力：画面の上にハート3つ。へったハートは うすい色になる
  - よけるものに当たると、ひよこが目をつぶって少しゆらゆらし「おっとっと」と出る（やさしい「ぽよん」の音）。
    ゆらゆらしている約1秒の間は、よけるものに当たってもはじくだけで、体力はへらない
  - はじめの3秒は、よけるものは出ない
- **せいげん じかん**：はじめの画面で「60びょう」「90びょう」「120びょう」「じかん なし」から選ぶ（最後に選んだものを覚えています）。
  時間があるときは、画面の上に のこり時間を大きく表示し、のこり10秒になると 数字の色が かわって やさしい音で知らせる
- 時間になるか、体力が0になったら「おしまい」。どちらで おわったか（「じかんに なったよ」「ハートが なくなったよ」）と、
  得点・とった食べものの数（しゅるいごと）・ランキングを表示し、「もういちど」「もくじ」を選べる
- ランキング：はじめに なまえ（イニシャルと色のマーク）を選ぶ。「おしまい」で「きろくを おくる」を押すと QRコードを出せる
  （「ランキング」を見てください）
- **むずかしさ**：30秒ごとにレベルが上がり、画面の まんなかに「レベル 3」のように大きく出る
  - 落ちる速さ：レベルごとに 約15％ずつ速くなる（レベル11で頭打ち）。落ちてくる数も 少しずつふえる
  - よけるもの（かみなり・いわ・さる）の わりあい：レベル1は 全体の15％、1レベルごとに5％ずつふえて、40％まで
  - よけるものが同時に落ちてくる数：レベル1〜2は1つずつ／3〜4は ときどき2つ／5〜6は 2つが ふえて ときどき3つ／7からは 3つが ふえる
  - 落ち方：レベル3から 横に ならんで同時に／レベル5から 少しずつ時間をずらして ななめに続けて／
    レベル7から 食べものの すぐ となりに よけるものが まざる（食べものの まうえに ひよこを あわせれば とれる）
  - **かならず にげみちを のこす**：どんなときも、同じころに落ちてくる よけるものの あいだに、ひよこの はばより広い すき間を
    かならず1か所以上のこす（のこせないときは、その よけるものを出さない）
- はやさ：はじめの画面で「ゆっくり」「ふつう」を選ぶ（最後に選んだものを覚えています）
- **ランキング**（この iPad の中）：「あそびかた（ゆび・こえ・め（iPad）・め（カメラ））」と「せいげん じかん」ごとに分けて、
  上位5つを日付といっしょに保存（ちがう条件の点数が まざらないように。名前は入れない。外部には何も送りません）。
  はじめの画面と「おしまい」の画面に、いま選んでいる条件のランキングを表示。いちばんの記録をこえたら「しんきろく！」と表示。
  「じかん なし」はランキングに入れない（「きろくを おくる」も出ない）。
  せいげん じかんが できる まえの ハイスコアは、この iPad の ランキングには出ません
- 音：キャッチ・ダメージ・レベルアップ・おしまいの効果音（ひかえめな音量）。「おと」ボタンでオン・オフ
- 「もくじ」ボタン：遊んでいる最中に押すと一時停止して「やめる？」と出る（「つづける」「はじめの がめん」「やめる」）。
  ほかのアプリに切り替えたときや、iPad の向きを変えたときも一時停止します
- 先生用：はじめの画面の右上の小さな「せってい」ボタンを **1秒ながおし** すると開く。
  ランキングの一覧（あそびかた・時間・日付・はやさつき）を見られ、「ランキングを けす」を2回おすと消える
- iPad の縦向き・横向きどちらでも遊べる
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

### こえで あそぶ（声の大きさだけで遊ぶモード）
手足が思うように動かない子が、声だけで遊べるモードです。言葉の聞き取り（音声認識）は使わず、マイクの **声の大きさ** だけを見ます。
録音・保存はせず、どこにも送りません。オフラインでも動きます。

- はじめの画面で「ゆびで あそぶ」「こえで あそぶ」を選ぶ（最後に選んだものを覚えています）
- ひよこの場所は左・右の2つだけ（地面にうすい丸の しるし）。声を出すたびに左右が入れかわる
- 食べものなどは、左か右の列の上から落ちてくる（同じ列が3回より多く続かない）
- 落ちる速さは、とてもゆっくりから始まり、レベルアップしても ゆるやかにしか速くならない（ゆびの 半分の 約7.5％ずつ）。
  最初の速さは「せってい」で「とても ゆっくり」「ゆっくり」「すこし ゆっくり」から選ぶ
- 同時に落ちてくる よけるものの数と 落ち方の むずかしさは、ゆびより 2レベル おそく ふえる
  （このモードと「めで あそぶ」は 左右2列なので、左右の両方に同時に よけるものを落とさない。どちらか片方は かならず安全。
  2つ以上のときは、同じ列に たてに ならぶか、左右 こうごに 時間をずらして落ちてくる）
- 1回入れかわったら、1秒は次の声に反応しない（声がのびても1回だけ。待ち時間は「せってい」で 0.7〜2秒に変えられる）。
  声が1度 線より下に下がってからでないと、次は反応しません
- ドアの音などの短い物音（0.08秒より短い音）には反応しない。ゲームの効果音が鳴った直後も、少しの間 反応しない
- 遊んでいる間は、画面の下に声の大きさのメーターと、反応する線を表示
- 「おしまい」のあと約2.5秒たつと「こえを だすと、もういちど あそべるよ」と出て、声で もう一度 遊べる
- 画面のタップや、スペース・エンターキー（外づけのスイッチなど）でも入れかわる（手伝う人や、スイッチを使う子のため）
- ハイスコアは「ゆび」と「こえ」で べつべつに上位5つ
- **こえテスト**：はじめの画面の「こえテスト」で、声の大きさのメーターと、反応する線を表示。
  「おおきく ▲」「ちいさく ▼」で線を動かして調整（病室の物音で動くときは「おおきく」）。
  調整した値は この iPad の中に保存され、声で遊ぶ ほかの教材とも共通です
- **マイクの許可**：マイクを使う前に、なぜ使うのかを やさしく表示してから、iPad の許可の確認を出します。
  許可しなかったときは「せってい」→「Safari」→「マイク」で許可できます、と表示します
- ほかのアプリに切り替えたときはマイクを止め、「つづける」を押すと また使います
- マイクを使っている間は、iPad の効果音が小さめに聞こえることがあります（iPad のしくみ）

### めで あそぶ（iPadの きのう）
目の動き（視線）で遊ぶモードです。iPad の「視線トラッキング」（iPadOS 18 以降。「設定」→「アクセシビリティ」→「視線トラッキング」）を
オンにして使います。指でタップしても遊べます。視線トラッキングに対応していない iPad（第8世代など）では、
次の「めで あそぶ（カメラ）」を使ってください。

- はじめの画面で「めで あそぶ（iPadの きのう）」を選ぶ
- ひよこの場所は左・右の2つだけ。行きたいほうを じっと見つめる（約0.6秒）と、ひよこが そちらへ動く。
  見つめている間は、ひよこの上の あたりに 丸い わが たまっていく
  - 視線トラッキングの「見つめてタップ（滞留コントロール）」で画面がタップされたときや、指でタップしたときは、タップしたほうへ すぐ動く
  - 左右の矢印キーでも動く
- 落ちてくる物は ほかのモードの3倍、ひよこは約1.5倍の大きさ。大きくしても、左右2列の物や ひよこが となりの列と重ならないように はなして並べる。
  同じ列で 物どうしが たてに重ならないように、上の ほうが あいてから 次の物を出す
- 落ちる速さ・数の増え方は「こえで あそぶ」と同じ（とても ゆっくり から始まり、速くなるのも ゆるやか）。
  最初の速さは「せってい」の「こえで あそぶ・めで あそぶ」で選ぶ（「めで あそぶ（カメラ）」も同じ）
- ハイスコアは「め」だけで べつに上位5つ
- 見つめているだけで動くのは、視線トラッキングのポインタが画面の上を動いているとき（ページに ポインタの位置が伝わるとき）です。
  伝わらない設定のときも、見つめてタップ（滞留コントロール）で動かせます

### めで あそぶ（カメラ）
iPad の まえの カメラ（インカメラ）の映像から、ページの中で 黒目の位置と 顔の向きを読み取って遊ぶモードです。
iPad の視線トラッキング機能を使わないので、**iPad 第8世代** など 視線トラッキングに対応していない iPad でも遊べます。
読み取りには MediaPipe の Face Landmarker を使います（`shared/mediapipe/`。外部からは読み込みません）。

- はじめの画面で「めで あそぶ（カメラ）」を選ぶ
- **カメラの許可**：カメラを使う前に、なぜ使うのかを やさしく表示してから、iPad の許可の確認を出します
- **めの じゅんび（キャリブレーション）**：ゲームの前に、暗めの画面に 大きな明るい丸（ひよこの顔。画面の短い辺の 約4分の1）が
  まんなか → 左 → 右 の順に出て、「ここを みてね」と読み上げる（音が「おと なし」のときは読み上げない）。丸は ゆっくり 大きくなったり 小さくなったりする
  - 丸が出てから 2秒は「見つける時間」（記録しない）。そのあと 1つの丸を **5秒** 見てもらう（丸の まわりの わが だんだん へっていく）。
    「せってい」で「ふつう（5びょう）」「ゆっくり（8びょう）」「とても ゆっくり（12びょう）」から選べる（全教材で共通。この iPad に保存）
  - 顔が見つからない・丸を見ていない（左・右で まんなかと同じほうを見ている）ときは、残り時間を止めて「まるを みてね」と やさしく読み上げる。見たら続きから
  - 1か所 記録できたら 小さな はなまるを出し、1秒 休んでから 次の丸へ。全部おわると「じゅんび できたよ」と表示して読み上げる
  - その結果から、その子の「ひだり」「まんなか」「みぎ」を決める。結果は この iPad に保存し、次からは「まえと おなじ」でとばせる
  - 顔が見えなかったり、左右の ちがいが わからなかったりしたときは「うまく いかなかったよ」と出て、「もういちど」でやり直せる
- ゲームでは、ひよこの場所は左右2列。左を見ると左、右を見ると右に動き、まんなかを見ているときは その場にとどまる
  - ちらっと見ただけで動かないように、同じほうを **0.5秒** 見続けたら動く（見ている間は わが たまっていく）。「せってい」で 0.3〜1.5秒に変えられる
- 判定に使うもの：「せってい」で「め」（黒目の位置）・「かお」（顔を すこし左右に向ける）・「りょうほう」（大きく動いたほう）から選ぶ。はじめは「りょうほう」
- 落ちてくる物は 3倍、ひよこは 約1.5倍。落ちる速さは「こえで あそぶ」と同じく とても ゆっくり から始まる（最初の速さは「せってい」）
- 顔が見つからないときは「かおが みえないよ」、部屋が暗くて読み取れないときは「へやを あかるくしてね」と出して、ゲームを止めて待つ（顔が見えたら そのまま続く）
- **しせんテスト**：はじめの画面の「しせんテスト」で、いま「ひだり」「まんなか」「みぎ」のどれと判定しているかを大きく表示する。
  「カメラの えいぞう：だす／ださない」で、カメラの映像を小さく出すかを切り替えられる（ゲーム中も 下に小さく出る）。「あわせなおす」で キャリブレーションをやり直せる
- ハイスコアは「カメラ」だけで べつに上位5つ
- **プライバシー**：カメラの映像は この iPad の ページの中だけで処理し、保存も送信もしません（録画もしません）。
  保存するのは、キャリブレーションの結果（数字だけ）と せっていだけです
- **軽く動かす工夫**（第8世代でも ゲームがカクカクしないように）：カメラの映像は 320×240 くらいの小さな解像度で読み取り、
  判定は 1秒に15回まで。使えるときは GPU で計算する（使えないときは CPU）。部屋の明るさは 1秒に1回、とても小さくした画像で調べる
- **オフライン**：MediaPipe のファイル（ぜんぶで 約25MB）は、はじめて「めで あそぶ（カメラ）」を使ったときに
  `sw.js` が まとめて保存します。そのあとは オフラインでも使えます。**はじめての1回は、インターネットにつながった ところで** 使ってください
  （大きいので、教材の版を上げても 取り直さないように、べつの保存場所 `kyozai-shisen-…` に入れています）

## もんだいの すすめかた（共通の部品 `shared/mondai.js`）
問題に答える教材（かずあそびの「いくつかな」・とけいの「なんじかな」・おかね・けいさん・きせつクイズ）は、
どれも同じ動きになるように、この部品を使っています（見た目は `shared/mondai.css`）。

- 正解したとき：やさしい音・はなまる（答えのボタンの上）・キラキラが出る。
  3秒後に自動で次の問題へ進む。待っている間は上に「タップで つぎへ」と のこり時間のバーが出て、画面のどこかをタップすると すぐ次へ
- まちがえたとき：これまでどおり「もういちど」と出て、同じ問題にもう一度答えられる。
  その問題は、あとで正解しても「まちがえた もんだい」として記録しておく
- 10問で一区切り（きせつクイズは1ジャンルの問題数＝5問）。画面の上に「3/10」のように何問目かを出す
- おわったとき：「10もんちゅう 〇もん せいかい」を大きく表示（1回目で答えられた問題だけ数える）。
  はなまるとやさしい音、読み上げは「がんばったね！」（全問正解のときは「ぜんぶ せいかい！すごいね！」）
  - ボタン：「まちがえた もんだいを もういちど」（まちがえた問題があるときだけ）・「つぎの 10もん」・「もくじ」
  - 「まちがえた もんだいを もういちど」：まちがえた問題だけを もう一度出す。おわると同じように「〇もんちゅう 〇もん せいかい」。
    それでもまちがえた問題があれば、また もう一度やるボタンが出る
- 待つ時間：先生用の「せってい」（1秒ながおし）で 2・3・4・5秒から選ぶ（はじめは3秒）。
  この iPad の中（ブラウザの保存領域）に保存し、この部品を使う教材すべてで共通です
- 記録（どの問題をまちがえたか）は その画面の中だけで使い、保存も送信もしません
- 教材に入れるとき：`Mondai.create({ area, countIn, total, make, show, speak })` で作り、
  正解で `correct(ボタン)`、まちがいで `wrong()` をよぶ（くわしくは `shared/mondai.js` の上の説明）

## しせん（共通の部品 `shared/shisen.js`）
カメラの映像から「ひだり」「まんなか」「みぎ」の どれを見ているかを判定する部品です。ほかの教材でも使えます。

```html
<script src="../shared/shisen.js"></script>
```
```js
var eye = Shisen.create({
  onDir: function (dir) { /* 'left' / 'center' / 'right' / null（顔が見えない） */ },
  onStatus: function (st) { /* 'loading' / 'ok' / 'noface' / 'dark' */ }
});
// ボタンを押したとき：なぜカメラを使うかを見せてから、許可 → 読み込み
Shisen.explain({ eye: eye, onOk: function () {
  Shisen.calibrate(eye, { onDone: function () { /* ゲームを はじめる */ } });  // 「まえと おなじ」も えらべる
} });
eye.stop();   // 使い終わったら カメラを止める
```

| 名前 | 内容 |
| --- | --- |
| `Shisen.create(設定)` | センサーを作る（カメラはまだ使わない）。`onDir`・`onStatus`・`source`（`'eye'`／`'face'`／`'both'`） |
| `eye.start()` / `eye.stop()` | カメラと MediaPipe を使い始める（Promise）／止める |
| `eye.getDir()` / `eye.getStatus()` / `eye.getScore()` | いまの判定／ようす／-1（ひだり）〜+1（みぎ）の値 |
| `eye.setSource(…)` / `eye.setCalib(…)` | 判定に使うもの／キャリブレーションの結果を変える |
| `eye.showPreview(要素 または null)` | カメラの映像を その要素の中に（左右反転して）出す／かくす |
| `Shisen.explain({ eye, onOk, onCancel, purpose })` | カメラを使う前の説明 → 許可 → 読み込み（読み込み中は「じゅんびしています…」）。`purpose` は 何のために使うか（例：`'えを ぬる'`。はじめは「ひよこを うごかす」） |
| `Shisen.calibrate(eye, { onDone, onCancel, speak, askSame })` | キャリブレーション（まんなか・左・右。見つける時間 2秒 → 記録 5／8／12秒 → 休み 1秒。見ていない間は 止まる）。`askSame: false` で「まえと おなじ」をきかない |
| `Shisen.openTest(eye, { onClose })` | しせんテストの画面 |
| `Shisen.loadSettings()` / `Shisen.saveSettings({ source, dwell, preview, calSec })` | せってい（保存名 `shisen-v1`。全教材で共通。`calSec` は キャリブレーションで1つの丸を見る秒数 5・8・12） |
| `<button data-ss-cal="5／8／12">` | 教材の「せってい」に置くと、キャリブレーションの 見る時間を えらぶボタンになる（押したときの保存と 表示は `shisen.js` が する） |
| `Shisen.loadCalib()` / `Shisen.saveCalib(…)` | キャリブレーションの結果（保存名 `shisen-calib-v1`） |

- 判定のしくみ：顔の点から「黒目が 目じりと目がしらの間の どこにあるか」と「鼻の先が 左右のほおの間の どこにあるか」を数にし、
  キャリブレーションで はかった 左・まんなか・右の値と くらべる。左右の値の半分より外に出たら「ひだり」「みぎ」、
  もどるときは もう少し内側まで もどったら「まんなか」（ゆれで いったりきたり しないように）
- 使う教材は `sw.js` の `ASSETS` に `./shared/shisen.js` を入れてください（`shared/mediapipe/` は `SHISEN_ASSETS` で別に保存します）

## こえスイッチ（共通の部品 `shared/koe-switch.js`）
マイクの声の大きさで「スイッチを押した」ことにする部品です。ほかの教材でも使えます。
言葉の聞き取りはせず、録音・保存も、外部への送信もしません（ページの中で大きさを計算するだけ）。

### 使い方
```html
<script src="../shared/koe-switch.js"></script>
<script src="./mykyozai.js"></script>
```
```js
var conf = KoeSwitch.loadSettings();      // この iPad に保存した しきい値・待ち時間（全教材で共通）
var sw = KoeSwitch.create({
  threshold: conf.threshold,              // 0〜1。この大きさを こえた声で反応（ふつう 0.5）
  cooldown: conf.cooldown,                // 反応したあと、次に反応するまでの ミリ秒（ふつう 1000）
  onTrigger: function () { /* 声でスイッチが押されたとき */ },
  onLevel: function (level, threshold) { /* 毎こま。メーター用（level は 0〜1） */ }
});

// ボタンを押したとき（タップの中）に start を呼ぶ。iPad ではタップの中でないと動きません
button.addEventListener('click', function () {
  sw.start().catch(function (err) { alert(KoeSwitch.errorMessage(err)); });
});
sw.stop();   // マイクを止める（使い終わったら・ほかの画面に移るとき）
```

| 名前 | 内容 |
| --- | --- |
| `KoeSwitch.create(設定)` | スイッチを作る。設定は `threshold`・`cooldown`・`minDuration`（この ミリ秒以上 続いた声だけ反応。ふつう 80）・`needQuiet`（1度 線より下に下がるまで次は反応しない。ふつう true）・`onTrigger`・`onLevel`・`onStop`（マイクが止められたとき） |
| `sw.start()` / `sw.stop()` | マイクを使い始める（Promise を返す）／止める |
| `sw.enabled` | `false` の間は、大きさは はかるが反応しない（一時停止中など） |
| `sw.setThreshold(0〜1)` / `sw.getThreshold()` | 反応する大きさ（しきい値） |
| `sw.setCooldown(ミリ秒)` / `sw.getCooldown()` | 反応したあとの待ち時間 |
| `sw.ignoreFor(ミリ秒)` | しばらく反応しない（教材が自分で効果音を鳴らすとき、マイクが それを拾わないように） |
| `sw.getLevel()` / `sw.isRunning()` | いまの大きさ（0〜1）／マイクを使っているか |
| `KoeSwitch.loadSettings()` / `KoeSwitch.saveSettings({ threshold, cooldown })` | しきい値・待ち時間を この iPad に保存・読み込み（保存名 `koe-switch-v1`。全教材で共通） |
| `KoeSwitch.errorMessage(err)` | マイクが使えなかったときの、やさしい説明の文 |
| `KoeSwitch.isSupported()` | この ブラウザで使えるか |

- 大きさは、マイクの音の強さ（-60dB〜-6dB）を 0〜1 にしたものです
- マイクの許可は https のページでだけ求められます（公開URL は https なので大丈夫です）
- マイクを使う前に、なぜ使うのかを画面に やさしく表示してから `start()` を呼んでください（「たべもの キャッチ」の `micAsk` が例です）
- 使う教材は、`sw.js` の `ASSETS` に `./shared/koe-switch.js` が入っていることを確認してください

## おしらせ
メニューの右上の「おしらせ」ボタンで、これまでの更新を新しい順に表示します（日付・どの教材か・何をしたか）。

  - `targets` は教材のフォルダ名（いくつでも）。メニュー全体は `menu`、ランキングは `ranking`

## ランキング（きろくを あつめる）
ぴよぴよ ラン・たべもの キャッチ・しんけいすいじゃく の記録を、複数の iPad から1台に集めてランキングにします。
**ネットは使わず**、QRコードで記録をわたします。

### こどもの iPad（ゲーム）
- **なまえ（イニシャル）**：ゲームを始める前に、アルファベット2文字（例：T.K）を大きなボタンで選ぶ。
  同じイニシャルの子を見分けられるように、**色のマーク**も8種類から1つ選ぶ
  （あか・まる／オレンジ・さんかく／きいろ・ほし／みどり・しかく／みずいろ・ひしがた／あお・ハート／むらさき・じゅうじ／ピンク・しずく。
  色が見分けにくい子でも分かるように、形も変えています）
- 選んだイニシャルと色は その iPad に保存し、次からは聞かない。はじめの画面の「T.K ● なまえを かえる」を押すと変えられる
  （ぴよぴよ ラン：画面の上／たべもの キャッチ：スタートの上／しんけいすいじゃく：「はじめる」の上。ふたりで遊ぶときは出ない）
- ゲームが終わったら「**きろくを おくる**」ボタンが出る。押すと記録の QRコードを大きく表示する
  - ぴよぴよ ラン：ゴールしたとき（むずかしい で「おしまい」になったときは出ない）。どんぐりの数・むずかしさ・ステージ
  - たべもの キャッチ：「おしまい」のとき。点数と、あそびかた・せいげん じかん（ゆび・60びょう など）。
    「じかん なし」で あそんだときは出ない。せいげん じかんが できる まえの きろくは「ゆび・ふつう（まえの きろく）」のように べつに ならぶ
  - しんけいすいじゃく：ひとりで全部そろえたとき。めくった回数と時間・むずかしさ
- QRコードの中身：ゲームの名前・むずかしさ（・ステージ）・点数（または どんぐりの数、めくった回数と時間）・イニシャル・色・日時・
  記録ごとの しるし（同じ記録を2回読んでも重ならないように）。名前（フルネーム）や顔などは入りません

### あつめる係の iPad（先生用）
- メニューの右上の「せってい」を **1秒ながおし** →「**ランキングを あつめる**」
- 「QRコードを よみとる」：カメラで こどもの iPad の QRコードを写すと、記録が追加される。
  読み取ると「T.K さんの きろくを うけとったよ」と表示（小さな音も鳴る）。右に、受け取った記録の一覧が出る
  - 「インカメラに する」「そとの カメラに する」で切り替え（最後に使ったほうを覚えています）
  - 同じ QRコードを2回読んでも重ならない（「もう うけとって いるよ」と出る）。記録以外の QRコードは「きろくでは ないよ」
  - **カメラの映像は保存も送信もしません**（QRコードを読むために1枚ずつ見て、すぐ捨てます）。「おわる」でカメラを止める。
    ほかのアプリに切り替えたときも止めます
  - はじめて使うときは、iPad がカメラの許可を聞きます。「許可」を押してください
- ランキング：ゲームごと・むずかしさごと（ぴよぴよ ランは ステージごとも）に、上位10位までをイニシャルと色のマークで大きく表示。
  横向きは5位ずつ2列、縦向きは1列
  - 「きょう」「ぜんぶ」で切り替え（「ぜんぶ」のときは日付も出る）
  - 並べかた：ぴよぴよ ラン・たべもの キャッチは数が多いほど上。しんけいすいじゃくは めくった回数が少ないほど上
    （同じ回数なら時間が短いほう）。点数が同じなら同じ順位
  - 同じ子（イニシャルと色が同じ）は、いちばん良い記録だけを出す
  - むずかしさのボタンは、記録があるものだけ出る
- 保存：ランキングは この iPad の中（ブラウザの保存領域）に保存。外部には何も送りません
- 「**かきだす**」：ランキングを CSV ファイル（`ranking-年-月-日.csv`）に保存。iPad では共有の画面が出るので
  「"ファイル" に保存」を選ぶ。Excel・Numbers でも開けます（列：id・game・game_name・diff・diff_name・stage・score・
  time_ms・initials・color・color_name・played_at・played_at_ms）
- 「**よみこむ**」：書き出した CSV を読み込んで元に戻す（今ある記録に足す。同じ記録は重ならない）
- 「**ぜんぶ けす**」：2回確認してから、集めた記録を全部消す
- オフラインでも使えます

## ゲームの パスワード
授業中に子どもが かってにゲームを開かないように、ゲーム（ぴよぴよ ラン・たべもの キャッチ・よんもくならべ・リバーシ・しょうぎ）は
数字4けたのパスワードを入れないと遊べません。

- メニューでゲームのボタンを押すと、パスワードの画面が出る（ボタンに「パスワード」と かぎの しるし）
  - 大きな数字ボタンで入れる。入れた数字は ● で かくれる。「けす」で1つ、「ぜんぶ けす」で全部消す
  - 正しければゲームが開く。まちがえたら「ちがうよ。もういちど いれてね」と出る
- 一度開いたら、ゲームを終えてメニューに戻るまでは聞かない（ゲームの中で「もういちど」やページの再読み込みをしても聞かない）
- メニューを通らずに ゲームのページを直接開いたときや、「もどる」で ゲームに戻ったときも、パスワードを聞く
- はじめのパスワードは **0000**
- **パスワードを変える**：メニューの右上の小さな「せってい」ボタンを **1秒ながおし** →「ゲームの パスワードを かえる」→
  いまのパスワード → 新しいパスワード → もう一度 新しいパスワード（1回目と ちがうときは、新しいパスワードから やりなおし）
- 変えたパスワードは この iPad の中（ブラウザの保存領域）にだけ保存し、プログラムの中には書きません。
  保存するのは数字そのものではなく、そこから計算した値です。ほかの iPad には うつりません
- オフラインでも使えます
- 子どもが かってに開かないための しくみです。大事な情報を守るための かぎ ではありません

### パスワードを わすれたとき
この iPad に保存したサイトのデータを消すと、パスワードは **0000** に戻ります。

- **Safari で開いているとき**：iPad の「設定」→「アプリ」→「Safari」→「詳細」→「Webサイトデータ」で、
  `tomo76922.github.io` を左にスワイプして「削除」する（iPadOS 17 までは「設定」→「Safari」→「詳細」→「Webサイトデータ」）
- **ホーム画面に追加して使っているとき**：ホーム画面のアイコンは Safari とは べつにデータを持っています。
  上の方法で戻らないときは、ホーム画面のアイコンを長押しして削除し、Safari で公開URLを開いて もう一度「ホーム画面に追加」する
- 消すと、ゲームの記録（クリアしたステージ・どんぐり・ハイスコア）や、はやさ・音・こえテストの設定、
  ランキング用の なまえ、集めたランキングも消えます（ランキングは先に「かきだす」で保存しておいてください）
- オフライン用の保存も消えるので、消したあとは一度 ネットにつながった状態でメニューを開いてください

### 共通の部品 `shared/game-lock.js`（ゲームを ふやすとき）
- ゲームのページ：`<body>` の すぐ あとに `<script src="../shared/game-lock.js" data-guard="ゲームの名前"></script>` を書く
  （メニューでパスワードを入れて開いていなければ、ページを開いたときに聞く）
- メニュー：ゲームの `<a class="menu-item">` に `data-lock="ゲームの名前"`（`data-guard` と同じ）と
  `data-lock-name="画面に出す名前"` を つける（`menu.js` が `GameLock.bindMenu()` で聞く）
- そのほか：`GameLock.ask({ onOk })`（パスワードを聞く）、`GameLock.change()`（パスワードを変える画面）、
  `GameLock.check('1234')`（正しいか）

## 教材をふやすとき
1. 新しいフォルダ（例：`tokei/`）を作り、`index.html` などを置く
   - `<head>` で `../manifest.webmanifest` と `../common.css` を読み込む
   - 画面に「もくじ」ボタン（`<a class="home-btn" href="../">`）を置く
   - 最後に `<script src="../pwa.js"></script>` を読み込む
2. メニュー（`index.html`）に `<a class="menu-item">` を1つ足す
   - **どの なかまか決めて入れる**：`data-group` に `manabu`（まなぶ）・`tsutaeru`（つたえる）・`asobu`（あそぶ）・`tsukuru`（つくる）の
     どれかを書き、同じ なかまの ボタンの あとに置く（ボタンの色は なかまの色に自動でそろう）
   - `data-id` にフォルダ名、`data-short` にタブに出す短い名前を書く
   - 名前（`menu-label`）の下に、どんな教材かを短く書く（`<span class="menu-desc">`）
   - 声や視線で操作できるときは、`menu-marks` に「こえ」（`mark-koe`）・「め」（`mark-me`）のしるしを入れる
   - README の「メニュー」の表にも足す
   - ゲームのときは、パスワードを聞くようにする（「ゲームの パスワード」の「共通の部品」を見てください）
3. `sw.js` の `ASSETS` に新しいファイルを足し、`CACHE_VERSION` を上げる
4. `news.json` に「新しく 追加しました」の おしらせを1件足す

## 更新するとき
ファイルを変更したら `sw.js` の `CACHE_VERSION`（例：`v5` → `v6`）を上げてください。
あわせて `news.json` に おしらせを1件足してください（「おしらせ」を見てください）。
（`shared/mediapipe/` の ファイルは べつで、入れかえたときだけ `SHISEN_CACHE` の名前を変えます）

- ネットにつながっているときは、いつも最新のファイルを読み込みます。
  つながっていないときだけ、保存してある版を表示します。
- 新しい版に切り替わると、ページが自動で1回だけ再読み込みされます
  （タイマーが動いている間は再読み込みしません）。
