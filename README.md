全体で1つの PWA なので、一度開けばメニューも教材もオフラインで使えます。

## ひらがなカード
タップすると、その文字を読み上げるカードです。

- 五十音表の並び（5列）で大きなカードを表示
- 濁音・半濁音（が〜ぽ）25文字のカード
- 画面上のボタンで「あ〜ん」「が・ざ・だ・ば・ぱ」を切り替え
- 横向きでは五十音表と同じ縦の並び（右から あ行・か行…）になり、スクロールなしで全部見える
- タップで読み上げ（端末内の日本語音声を使用・外部サービスなし）
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## みえる タイマー
残り時間が色の部分の大きさで見えるタイマーです。

- 「1ぷん」「3ぷん」「5ふん」「10ぷん」で時間を選ぶ（最後に選んだ時間を覚えています）
- 円の色の部分が、時計の針と同じ向きに少しずつ減っていく
- 残りの分と秒も大きな数字で表示
- 「スタート」「とめる」「もどす」ボタン
- 時間になると、やさしいチャイム（ひかえめな音量）が2回鳴る。音はその場で作るので音のファイルは不要、オフラインでも鳴ります
- 動いている間は画面が暗くならないようにします（対応している iPad のみ。iPadOS 16.4 以降が目安）
- 縦向き・横向きどちらでもスクロールなしで使える

## きもちカード
気持ちや体の様子を、絵と言葉で伝えるカードです。

- 「きもち」：うれしい・たのしい・ふつう・かなしい・こわい・おこってる・さみしい
- 「からだ」：つかれた・ねむい・いたい・きもちわるい・さむい・あつい・のどがかわいた・おなかがすいた・トイレ
- 画面上のボタンで「きもち」「からだ」を切り替え
- 絵はページの中で描いているので、画像ファイルは不要。オフラインでも表示されます
- カードをタップすると、そのカードが画面いっぱいに大きく出て、言葉を読み上げます
  （先生や看護師さんに見せるときに）。もう一度タップすると一覧に戻ります
- 「ゆっくり」ボタンで読み上げ速度を遅くできる
- 横向きではスクロールなしで全部見える

## かずあそび
1から10までの数を、絵で数える教材です。

- 画面上のボタンで「かぞえる」「いくつかな」を切り替え
- 「かぞえる」：1〜10の数字をタップすると、その数だけいちごが1つずつ出てきて、
  「いち、に、さん…」と読み上げ、最後に「ぜんぶで さん」のように読み上げる（4は「よん」、7は「なな」）
- 「いくつかな」：いちご・ほし・はな・まるの絵の数を、下の数字ボタンから選ぶ。
  正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度選べる
- 「1〜5」「1〜10」で問題の範囲を切り替え（最後に選んだ範囲を覚えています）。「つぎ」で次の問題へ
- 絵は5こずつ2段に並ぶので、5と10のまとまりが見えやすい
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げと数える速さを遅くできる

## とけい
アナログ時計の読み方を練習する教材です。

- 画面上のボタンで「うごかす」「なんじかな」を切り替え
- 「うごかす」：1〜12の数字が入った大きな時計。長い針（青）を指でぐるっと動かすと、
  短い針（赤）も本物の時計と同じように少しずつ動く（12をこえると次の時へ進む）。
  指をはなすと、その時刻を読み上げる（例：「さんじ じゅうごふん」）
- 時刻の文字（例：3じ15ふん）は「じこくを かくす」「じこくを みせる」ボタンで出したり隠したりできる
- 「なんじかな」：時計の時刻を、3つの答えから選ぶ。
  むずかしさは「ちょうど」「ちょうど・はん」「5ふんごと」「1ぷんごと」（最後に選んだものを覚えています）。
  正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度選べる。「つぎ」で次の問題へ
- 読み方：じ は「よじ」「しちじ」「くじ」、ふん は「いっぷん・にふん・さんぷん・よんぷん・ごふん・
  ろっぷん・ななふん・はっぷん・きゅうふん・じゅっぷん」（15は「じゅうごふん」、20は「にじゅっぷん」）。
  30分は「さんじゅっぷん」と読み、「ちょうど・はん」のときだけ「はん」と表示・読み上げる
- 時計も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## よていボード
きょうの予定を、絵とひらがなのカードで上から順に並べるボードです。

- 子どもが見る画面：カードをタップすると言葉を読み上げ、「おわり」になって はなまるが付き、少しうすくなる。
  もう一度タップすると元に戻る（あわてて2回タップしたときは戻りません）
- まだ終わっていない一番上のカードが「いま」として大きく、色付きの枠で目立つ。ぜんぶ終わると「ぜんぶ おわったね」と出る
- 先生が並べる画面：右上の小さな「せってい」ボタンを **1秒ながおし** したときだけ開く（短く押すと「ながく おして ください」と出るだけ）
  - 用意されたカード（あさのかい・べんきょう・やすみじかん・おひるごはん・うんどう・あるく・おんがく・かんさつ・
    ぼっちゃ・ぎょうじ・おたのしみ・かえりのかい）から選んで、予定の最後に追加
  - 言葉を入力して自分のカードも作れる（12文字まで。絵は、最初の1文字を丸の中に書いたもの）
  - ▲▼で順番の入れかえ、「けす」でカードを消す
  - 時刻は入れても入れなくてもよい（入れるとカードに小さく表示。×で消せる）
  - 「はなまるを ぜんぶ けす」で、次の日のために印だけリセット
- 並べた予定は この iPad の中（ブラウザの保存領域）に自動で保存し、次に開いたときも残っています。外部には何も送りません
  （Safari の「履歴とWebサイトデータを消去」をすると消えます）
- はじめて開いたときは、れいとして5枚のカードが並んでいます
- 絵はページの中で描いているので、画像ファイルは不要。オフラインでも表示されます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## おかね
お金を数えたり、買いものやおつりを練習したりする教材です。

- お金の絵：1円・5円・10円・50円・100円・500円の硬貨と、1000円札。
  本物とまちがえないように、色・大きさ・金額の数字だけで区別するシンプルな絵です（本物の模様や肖像はなし。お札には「みほん」）。
  大きさは本物と同じじゅんばん（1円 ＜ 50円 ＜ 5円 ＜ 100円 ＜ 10円 ＜ 500円）で、少し差を大きくしています
- レベル（上の 1〜7 のボタンで選ぶ。まだひらいていないレベルはかぎのマーク）
  - レベル1：1円玉だけ（10円まで）
  - レベル2：10円玉と1円玉（100円まで）
  - レベル3：5円玉・50円玉も入る（100円まで）
  - レベル4：100円玉・500円玉も入る（1000円まで）
  - レベル5：1000円札も入る（2000円まで）
  - レベル6：かいもの（品物の絵とねだんを見て、下のお金をタップしてトレイに出す。トレイのお金はタップで戻せる。「これでいい」で答え合わせ）
  - レベル7：おつり（品物のねだんと出したお金を見て、おつりを数字ボタンで答える）
- レベル1〜5は「いくら？」：並んだお金の合計を答える。レベル1〜3は3つの答えから選び、レベル4・5は数字ボタンで入力（「けす」で1文字消す）。
  お金を1つずつタップすると、たした金額を「じゅう、にじゅう、にじゅうご…」と読み上げ、数えたお金はうすくなる（「かぞえなおす」で最初から）
- 正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度答えられる。「つぎ」で次の問題へ
- 正解するたびに星が1つたまり、5つたまると「レベルアップ！」と出て やさしい音が鳴り、次のレベルがひらく。
  ひらいたレベルと星は この iPad の中（ブラウザの保存領域）に保存し、次も続きからできる。外部には何も送りません
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - まだひらいていないレベルも含めて、どのレベルでも選べる（各レベルの星の数も見られる）
  - 「きろくを リセット」を2回おすと、ひらいたレベルと星を消してレベル1に戻す
- 読み方：金額はひらがなで読み上げる（4円「よえん」、300円「さんびゃくえん」、600円「ろっぴゃくえん」、
  800円「はっぴゃくえん」、1000円「せんえん」など）
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## きせつクイズ
季節の花・虫・行事・食べ物・歌を、絵を見て当てるクイズです。

- 画面の流れ：学年 → 季節 → ジャンル → クイズ。どの画面にも「もどる」ボタンがあります
  - 学年：小1〜小6・中学・高校。選んだ学年は この iPad の中に保存し、次に開いたときは その学年のまま季節を選ぶ画面から始まります
  - 季節：春・夏・秋・冬（いまは春・夏・秋。冬は「じゅんびちゅう」と出て押せません）
  - ジャンル：花・虫・行事・食べ物・歌
- クイズ：大きな絵を見て「これは なに？」（歌は「これは なんの うた？」）に、3つの答えから選ぶ。
  まちがいの答えには、ほかの季節のものも かならず1つ入る
  - 問題が出ると、問題文と3つの答えを読み上げる（スピーカーのボタンで もう一度）
  - 正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度選べる。「つぎ」で次の問題へ
  - 1ジャンル5問。おわると、何問正解したかを星と文字で表示（1回目で正解した問題を数える）
- 春の問題
  - 花：さくら・たんぽぽ・チューリップ・なのはな・つくし・すみれ
  - 虫：ちょうちょう・てんとうむし・みつばち・おたまじゃくし・あり
  - 行事：ひなまつり・入学式・お花見・こどもの日・卒業式・母の日
  - 食べ物：いちご・たけのこ・さくらもち・春キャベツ・そらまめ
  - 歌：「春の小川」「ちょうちょう」「どこかで春が」「春が来た」「チューリップ」「おぼろ月夜」
    （歌の様子がわかる絵から題名を選ぶ。歌詞とメロディは入れていません）
- 夏の問題
  - 花：ひまわり・朝顔・ハイビスカス・あじさい・ゆり
  - 虫：せみ・かぶと虫・くわがた・ほたる・か
  - 行事：七夕・夏祭り・花火大会・海水浴・ラジオ体操
  - 食べ物：すいか・とうもろこし・かき氷・トマト・きゅうり・なす
  - 歌：「うみ」「たなばたさま」「かたつむり」「ほたるこい」「夏は来ぬ」
- 秋の問題
  - 花：コスモス・菊・ひがんばな・きんもくせい・すすき
  - 虫：すず虫・とんぼ・ばった・かまきり・みの虫
  - 行事：運動会・お月見・ハロウィン・敬老の日・七五三
  - 食べ物：くり・さつまいも・かき・ぶどう・なし・さんま
  - 歌：「紅葉（もみじ）」「虫の声」「赤とんぼ」「村祭」「月」
- 学年に合わせた文字：文部科学省の学年別漢字配当表（2020年度から）に合わせて、画面の文字・問題文・答えを自動で切り替える
  - 小1：ひらがな・カタカナだけ
  - 小2〜小6：その学年までに習う漢字は漢字、まだ習わない漢字は ひらがな（例：小2「入学しき」、小3「入学式」）
  - 中学・高校：常用漢字を使う（例：「桜餅」「菊」）
  - 「ふりがな」ボタンで、漢字に ふりがなを付けたり消したりできる（最後の状態を覚えています）
  - 読み上げは、表示が漢字でも データの読み（ひらがな）で読むので、正しい読みになります
- 絵は iPad の絵文字と、ページの中で描いた絵（たんぽぽ・なのはな・つくし・たけのこ・朝顔・せみ・かぶと虫・菊・すず虫・かき・歌の場面など）。画像ファイルは不要で、オフラインでも表示されます
- 音もページの中で作るので、音のファイルは不要。オフラインでも鳴ります
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

### 問題の足し方（冬）
問題は `kisetsu/data.js` に書きます。

- 1問は `{ name: '答え', pic: '絵' }`。
  - `name`：漢字の言葉は `[漢字:よみ]` と書く。1字ずつの読みを `.` で区切ると、習った漢字だけ漢字になる
    （例：`[入学式:にゅう.がく.しき]`）。区切らないと言葉全体で1つ（例：`[七夕:たなばた]`）。
    `[ ]` の外には漢字を書かない。学年ごとに別々に書く必要はありません
  - `pic`：絵文字（例：`'🍉'`、2〜3こ並べてもよい）か、`'svg:なまえ'`（同じファイルの `PICS` に描いた絵）
  - `pic` がない言葉は、ほかの季節の「まちがいの答え」だけに使われる
- その季節の5つのジャンルすべてに、`pic` のある問題が5問以上そろうと、自動で選べるようになります
- 小学校で習わない常用漢字を使うときは、`kisetsu/kanji.js` の `JOYO_EXTRA` に足す
- 書きまちがい（`[ ]` の外の漢字、表にない漢字、読みの数のずれ）は、ブラウザのコンソールに出ます

## iPad での使い方
1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」でアプリのように使えます
3. 音が出ないときは、本体の音量・消音モード（サイレント）を確認してください。
   タイマーのチャイムも消音モードでは鳴りません
4. タイマーは、別のアプリに切り替えている間はチャイムが鳴りません。
   タイマーの画面を開いたままにしてください

## 教材をふやすとき
1. 新しいフォルダ（例：`tokei/`）を作り、`index.html` などを置く
   - `<head>` で `../manifest.webmanifest` と `../common.css` を読み込む
   - 画面に「もくじ」ボタン（`<a class="home-btn" href="../">`）を置く
   - 最後に `<script src="../pwa.js"></script>` を読み込む
2. メニュー（`index.html`）に `<a class="menu-item">` を1つ足す
3. `sw.js` の `ASSETS` に新しいファイルを足し、`CACHE_VERSION` を上げる

## 更新するとき
ファイルを変更したら `sw.js` の `CACHE_VERSION`（例：`v5` → `v6`）を上げてください。

- ネットにつながっているときは、いつも最新のファイルを読み込みます。
  つながっていないときだけ、保存してある版を表示します。
- 新しい版に切り替わると、ページが自動で1回だけ再読み込みされます
  （タイマーが動いている間は再読み込みしません）。
