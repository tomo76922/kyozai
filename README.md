## ひらがなカード
タップすると、その文字を読み上げるカードです。

- 五十音表の並び（5列）で大きなカードを表示
- 濁音・半濁音（が〜ぽ）25文字のカード
- 画面上のボタンで「あ〜ん」「が・ざ・だ・ば・ぱ」を切り替え
- 横向きでは五十音表と同じ縦の並び（右から あ行・か行…）になり、スクロールなしで全部見える
- タップで読み上げ（端末内の日本語音声を使用・外部サービスなし）
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## みえる タイマー
残り時間が色の部分の大きさで見えるタイマーです。

- 「1ぷん」「3ぷん」「5ふん」「10ぷん」で時間を選ぶ（最後に選んだ時間を覚えています）
- 円の色の部分が、時計の針と同じ向きに少しずつ減っていく
- 残りの分と秒も大きな数字で表示
- 「スタート」「とめる」「もどす」ボタン
- 時間になると、やさしいチャイム（ひかえめな音量）が2回鳴る。音はその場で作るので音のファイルは不要、オフラインでも鳴ります
- 動いている間は画面が暗くならないようにします（対応している iPad のみ。iPadOS 16.4 以降が目安）
- 縦向き・横向きどちらでもスクロールなしで使える

## きもちカード
気持ちや体の様子を、絵と言葉で伝えるカードです。

- 「きもち」：うれしい・たのしい・ふつう・かなしい・こわい・おこってる・さみしい
- 「からだ」：つかれた・ねむい・いたい・きもちわるい・さむい・あつい・のどがかわいた・おなかがすいた・トイレ
- 画面上のボタンで「きもち」「からだ」を切り替え
- 絵はページの中で描いているので、画像ファイルは不要。オフラインでも表示されます
- カードをタップすると、そのカードが画面いっぱいに大きく出て、言葉を読み上げます
  （先生や看護師さんに見せるときに）。もう一度タップすると一覧に戻ります
- 「ゆっくり」ボタンで読み上げ速度を遅くできる
- 横向きではスクロールなしで全部見える

## かずあそび
1から10までの数を、絵で数える教材です。

- 画面上のボタンで「かぞえる」「いくつかな」を切り替え
- 「かぞえる」：1〜10の数字をタップすると、その数だけいちごが1つずつ出てきて、
  「いち、に、さん…」と読み上げ、最後に「ぜんぶで さん」のように読み上げる（4は「よん」、7は「なな」）
- 「いくつかな」：いちご・ほし・はな・まるの絵の数を、下の数字ボタンから選ぶ。
  正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度選べる
- 「1〜5」「1〜10」で問題の範囲を切り替え（最後に選んだ範囲を覚えています）。「つぎ」で次の問題へ
- 絵は5こずつ2段に並ぶので、5と10のまとまりが見えやすい
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げと数える速さを遅くできる

## とけい
アナログ時計の読み方を練習する教材です。

- 画面上のボタンで「うごかす」「なんじかな」を切り替え
- 「うごかす」：1〜12の数字が入った大きな時計。長い針（青）を指でぐるっと動かすと、
  短い針（赤）も本物の時計と同じように少しずつ動く（12をこえると次の時へ進む）。
  指をはなすと、その時刻を読み上げる（例：「さんじ じゅうごふん」）
- 時刻の文字（例：3じ15ふん）は「じこくを かくす」「じこくを みせる」ボタンで出したり隠したりできる
- 「なんじかな」：時計の時刻を、3つの答えから選ぶ。
  むずかしさは「ちょうど」「ちょうど・はん」「5ふんごと」「1ぷんごと」（最後に選んだものを覚えています）。
  正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度選べる。「つぎ」で次の問題へ
- 読み方：じ は「よじ」「しちじ」「くじ」、ふん は「いっぷん・にふん・さんぷん・よんぷん・ごふん・
  ろっぷん・ななふん・はっぷん・きゅうふん・じゅっぷん」（15は「じゅうごふん」、20は「にじゅっぷん」）。
  30分は「さんじゅっぷん」と読み、「ちょうど・はん」のときだけ「はん」と表示・読み上げる
- 時計も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## よていボード
きょうの予定を、絵とひらがなのカードで上から順に並べるボードです。

- 子どもが見る画面：カードをタップすると言葉を読み上げ、「おわり」になって はなまるが付き、少しうすくなる。
  もう一度タップすると元に戻る（あわてて2回タップしたときは戻りません）
- まだ終わっていない一番上のカードが「いま」として大きく、色付きの枠で目立つ。ぜんぶ終わると「ぜんぶ おわったね」と出る
- 先生が並べる画面：右上の小さな「せってい」ボタンを **1秒ながおし** したときだけ開く（短く押すと「ながく おして ください」と出るだけ）
  - 用意されたカード（あさのかい・べんきょう・やすみじかん・おひるごはん・うんどう・あるく・おんがく・かんさつ・
    ぼっちゃ・ぎょうじ・おたのしみ・かえりのかい）から選んで、予定の最後に追加
  - 言葉を入力して自分のカードも作れる（12文字まで。絵は、最初の1文字を丸の中に書いたもの）
  - ▲▼で順番の入れかえ、「けす」でカードを消す
  - 時刻は入れても入れなくてもよい（入れるとカードに小さく表示。×で消せる）
  - 「はなまるを ぜんぶ けす」で、次の日のために印だけリセット
- 並べた予定は この iPad の中（ブラウザの保存領域）に自動で保存し、次に開いたときも残っています。外部には何も送りません
  （Safari の「履歴とWebサイトデータを消去」をすると消えます）
- はじめて開いたときは、れいとして5枚のカードが並んでいます
- 絵はページの中で描いているので、画像ファイルは不要。オフラインでも表示されます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## おかね
お金を数えたり、買いものやおつりを練習したりする教材です。

- お金の絵：1円・5円・10円・50円・100円・500円の硬貨と、1000円札。
  本物とまちがえないように、色・大きさ・金額の数字だけで区別するシンプルな絵です（本物の模様や肖像はなし。お札には「みほん」）。
  大きさは本物と同じじゅんばん（1円 ＜ 50円 ＜ 5円 ＜ 100円 ＜ 10円 ＜ 500円）で、少し差を大きくしています
- レベル（上の 1〜7 のボタンで選ぶ。まだひらいていないレベルはかぎのマーク）
  - レベル1：1円玉だけ（10円まで）
  - レベル2：10円玉と1円玉（100円まで）
  - レベル3：5円玉・50円玉も入る（100円まで）
  - レベル4：100円玉・500円玉も入る（1000円まで）
  - レベル5：1000円札も入る（2000円まで）
  - レベル6：かいもの（品物の絵とねだんを見て、下のお金をタップしてトレイに出す。トレイのお金はタップで戻せる。「これでいい」で答え合わせ）
  - レベル7：おつり（品物のねだんと出したお金を見て、おつりを数字ボタンで答える）
- レベル1〜5は「いくら？」：並んだお金の合計を答える。レベル1〜3は3つの答えから選び、レベル4・5は数字ボタンで入力（「けす」で1文字消す）。
  お金を1つずつタップすると、たした金額を「じゅう、にじゅう、にじゅうご…」と読み上げ、数えたお金はうすくなる（「かぞえなおす」で最初から）
- 正解なら やさしい音と「せいかい」（読み上げも）、まちがいなら「もういちど」と出て、もう一度答えられる。「つぎ」で次の問題へ
- 正解するたびに星が1つたまり、5つたまると「レベルアップ！」と出て やさしい音が鳴り、次のレベルがひらく。
  ひらいたレベルと星は この iPad の中（ブラウザの保存領域）に保存し、次も続きからできる。外部には何も送りません
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - まだひらいていないレベルも含めて、どのレベルでも選べる（各レベルの星の数も見られる）
  - 「きろくを リセット」を2回おすと、ひらいたレベルと星を消してレベル1に戻す
- 読み方：金額はひらがなで読み上げる（4円「よえん」、300円「さんびゃくえん」、600円「ろっぴゃくえん」、
  800円「はっぴゃくえん」、1000円「せんえん」など）
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで読み上げ速度を遅くできる

## けいさん
ブロックの動きを見ながら、たしざん・ひきざんを練習する教材です。

- レベル（上の 1〜6 のボタンで選ぶ。まだひらいていないレベルはかぎのマーク）
  - レベル1：たしざん（こたえが5まで）
  - レベル2：たしざん（こたえが10まで）
  - レベル3：ひきざん（10までの数から）
  - レベル4：たしざんとひきざんのまぜた問題（10まで）
  - レベル5：くりあがりのあるたしざん（9＋4 など。こたえは11〜18）
  - レベル6：くりさがりのあるひきざん（13−5 など）
- 式（例：3 ＋ 2 ＝ ？）の下に、数の分だけブロックを並べる。式をタップすると読み上げる
  - たしざん：青と黄色の2つのかたまりが、くっついて1つになる
  - ひきざん：とるブロックが横にはずれて、うすい点線になる（「とる 2」と表示）
  - くりあがり：10個入りのわく（2だん×5れつ）を2つ使い、黄色のブロックが1つずつ青のわくへ移って10ができる（「10」と表示）
  - くりさがり：10のわくから、とる数だけブロックが1つずつはずれていく
  - 問題が出ると少しあとに動く。「うごきを みる」またはブロックをタップすると、もう一度動く
- 「ヒント」：ブロックを1つずつ光らせて、番号を付けながら「いち、に、さん…」と読み上げる（もう一度おすと止まる）
- 答えは下の数字ボタンで（レベル1は1〜5、レベル2〜4は1〜10、レベル5は10〜18、レベル6は1〜9）
- 正解なら やさしい音と「せいかい」、式と答えを読み上げる（例：「さん たす に は ご」）。
  まちがいなら「もういちど」と出て、ブロックの動きをもう一度見せる。「つぎ」で次の問題へ
- 正解するたびに星が1つたまり、5つたまると「レベルアップ！」と出て次のレベルがひらく。
  ひらいたレベルと星は この iPad の中（ブラウザの保存領域）に保存。外部には何も送りません
- 先生用：右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - まだひらいていないレベルも含めて、どのレベルでも選べる（各レベルの星の数も見られる）
  - 「きろくを リセット」を2回おすと、ひらいたレベルと星を消してレベル1に戻す
- ブロックも音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます
- 「ゆっくり」ボタンで、読み上げ・ブロックの動き・ヒントの数える速さを遅くできる

## きせつクイズ
季節の花・虫・行事・食べ物・歌を、絵を見て当てるクイズです。

- 画面の流れ：学年 → 季節 → ジャンル → クイズ。どの画面にも「もどる」ボタンがあります

### 問題の足し方
問題は `kisetsu/data.js` に書きます。

- 1問は `{ name: '答え', pic: '絵' }`。
  - `name`：漢字の言葉は `[漢字:よみ]` と書く。1字ずつの読みを `.` で区切ると、習った漢字だけ漢字になる
    （例：`[入学式:にゅう.がく.しき]`）。区切らないと言葉全体で1つ（例：`[七夕:たなばた]`）。
    `[ ]` の外には漢字を書かない。学年ごとに別々に書く必要はありません
  - `pic`：絵文字（例：`'🍉'`、2〜3こ並べてもよい）か、`'svg:なまえ'`（同じファイルの `PICS` に描いた絵）
  - `pic` がない言葉は、ほかの季節の「まちがいの答え」だけに使われる
- その季節の5つのジャンルすべてに、`pic` のある問題が5問以上そろうと、自動で選べるようになります（問題は5問より多くてもよい。毎回その中から5問を選ぶ）
- 小学校で習わない常用漢字を使うときは、`kisetsu/kanji.js` の `JOYO_EXTRA` に足す
- 書きまちがい（`[ ]` の外の漢字、表にない漢字、読みの数のずれ）は、ブラウザのコンソールに出ます

## なぞりがき
ひらがな・カタカナ・すうじを、書き順どおりに指（Apple Pencil でも）でなぞる教材です。

- 画面上のボタンで「ひらがな」「カタカナ」「すうじ（0〜9）」を切り替え（最後に選んだものを覚えています）
- 一覧（ひらがな・カタカナは五十音表の並び。横向きでは右から あ行・か行…）から文字を選ぶと、なぞる画面になる
- なぞる画面
  - お手本の文字を、マスいっぱいに うすく大きく表示。いまなぞる画は少し色が付く
  - 書き順の番号と、書きはじめの位置に点を表示（いまなぞる画の点は赤くて、ゆっくり大きくなったり小さくなったりする）
  - 1画ずつ、正しい書き順でなぞれたら小さな「ポン」という音がして、次の画へ進む。
    多少はみ出しても、少し短くても大丈夫なくらい、判定はやさしめ（「ふとい」のときは さらに少しやさしい）
  - 書き順がちがったとき（例：2画目を先に書いた）、反対の向きに書いたとき、大きくはずれたときは、
    その画をそっと消して「もういちど」と表示（「1ばんから かこうね」「●の ほうから かこうね」「うすい せんを なぞってね」のどれか）
  - 全部なぞれたら、はなまると やさしい音（ひかえめな音量）。そのあと文字の読みを読み上げる
    （カタカナは ひらがなと同じ読み、「を」は「お」、すうじは「ぜろ・いち・に・さん・よん・ご・ろく・なな・はち・きゅう」）
  - 右（縦向きでは下）の大きな文字をタップすると、読みを読み上げる
  - 「おてほん」：書き順どおりに、1画ずつ線が書かれていくアニメーション（もう一度おすと止まる。なぞりはじめても止まる）
  - 「けす」：その文字をはじめからやり直す。「つぎ」：次の文字へ（最後の文字の次は最初の文字）。「いちらん」：文字の一覧に戻る
- 線の太さ：右上の「ふつう」「ふとい」から選ぶ（最後に選んだものを覚えています）
- Apple Pencil で書いているときは、画面に手のひらが当たっても線になりません
- なぞれた文字は、一覧で小さな赤い丸が付く（この iPad の中に保存。外部には何も送りません）
- 音はページの中で作るので、音のファイルは不要。書き順のデータもリポジトリに入れてあるので、オフラインで使えます

## しんけいすいじゃく
裏向きに ならべた カードを 2まいずつ めくって、同じ絵を さがす教材です。

- はじめの画面で むずかしさと あそぶ人を えらんで「はじめる」（最後に えらんだものを覚えています）
  - やさしい：16まい（8ペア）・4×4。オリジナルの どうぶつ8種類（うさぎ・くま・ねこ・いぬ・ぞう・ぱんだ・ひよこ・きつね）
  - ふつう：32まい（16ペア）・横向きは 8×4、縦向きは 4×8。栃木県の名物の食べもの16種類
    （いちご・ぎょうざ・かんぴょう・しもつかれ・ゆば・レモン牛乳・佐野ラーメン・耳うどん・ちたけそば・いもフライ・
    ポテト入り焼きそば・日光ようかん・たまり漬け・にら・とちぎ和牛・とうがらし）。絵の下に ひらがなで名前を小さく書く
  - むずかしい：64まい（32ペア）・8×8。トランプ2組を使い、52種類から ランダムに32種類をえらんで、同じマーク・同じ数字の2まいがペア。
    数字（A・2〜10・J・Q・K）とマーク（♠♥♦♣）を大きく、赤と黒で色分け。J・Q・K は数字の下に線
- どのむずかしさでも、画面の大きさ・向きに合わせてカードの大きさを変え、スクロールなしで おさまる（向きを変えると並べ直す）
- タップすると表になる。2まい めくって同じなら ペア成立（やさしい音と小さなキラキラ。カードは表のまま残り、ふちが金色になる）。
  ちがったら1秒後に裏に もどる（その間は ほかのカードを めくれない）
- 画面の上に「めくった かいすう」（2まい めくって1回）と「じかん」（1まいめを めくったときから数える）
- 全部そろったら、はなまると回数・時間を表示。「もういちど」「はじめの がめん」を えらべる
- きろく：ひとりで遊んだときの、むずかしさごとの いちばん少ない回数を この iPad の中（ブラウザの保存領域）に保存。
  はじめの画面の ボタンに「いちばん ○かい」と出る。記録を更新したら「しんきろく！」と表示
- ふたりで：交代で めくる（そろったら同じ人が もう一度めくれる。ちがったら交代）。画面の上に「ひとりめ」「ふたりめ」の
  そろえたペアの数と、どちらの ばんかを表示。そろえたカードのふちは その人の色（ピンク・青）。
  終わったら「○○の かち！」か「ひきわけ！」と出る。ふたりのときは記録は残さない
- 「おと」ボタンで音のオン・オフ（遊んでいる間は マークだけになる）
- ランキング：ひとりで遊ぶときは、はじめに なまえ（イニシャルと色のマーク）を選ぶ。全部そろえたら「きろくを おくる」で
  QRコードを出せる（「ランキング」を見てください）
- 「もくじ」ボタン：遊んでいる最中に押すと「やめる？」と出る（「つづける」「はじめの がめん」「やめる」）。その間と、
  ほかのアプリに切り替えている間は、時間を止める
- カードの裏は ほかの教材と同じ落ち着いた みどり。表は白地に太い ふちどりの絵で、はっきり見えるようにしている
- 絵（`art.js`）はすべてプログラムで描いた オリジナルで、既存のキャラクターや 実在の商品のパッケージ・ロゴは描いていない。
  音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

## ぴよぴよ ラン
ひよこが右へ自動で走る、横スクロールのゲームです。開くときにパスワードがいります。

- はじめの画面で、ステージ・あそびかた・むずかしさを選ぶ（あそびかたと むずかしさは この iPad に保存し、次も同じ）
- **ゆびで あそぶ**：画面のどこかをタップするとジャンプ（少し早めにタップしても、着地したらすぐ跳びます）
- **こえで あそぶ**：声を出すとジャンプ。共通の部品 `shared/koe-switch.js` を使い、声の大きさだけで判定する
  （音声認識はしない・録音しない・オフラインで動く）。指でタップしてもジャンプできます
  - はねを取っているときは、空中でもう一度 声を出すと2段ジャンプ
  - 声がのびて何度もジャンプしないように、1回ジャンプしたら0.4秒は次の声に反応しない
    （「せってい」で 0.3・0.4・0.6・0.8・1びょう から選べる。この待ち時間は この ゲームだけの設定）。
    声がいったん小さくなるまでも反応しません
  - はじめの画面の「こえテスト」で、声の大きさのメーターと反応する線を見ながら、反応する大きさ（しきい値）を変えられる。
    しきい値は「たべもの キャッチ」と同じ設定（共通の保存）を使う
  - はじめて使うときは、マイクを使う理由を やさしく表示してから、iPad の許可をたずねる
  - 遊んでいる間は、画面の下に声の大きさのメーターが出る
- アイテム
  - どんぐり：道や空中に並んでいて、取ると右上の数がふえる。ジャンプして取る高い位置に どんぐりがあるときは、
    その真下の地面には置かない（跳ぶかどうか迷わないように）
  - はね：取ると10秒の間、空中でもう1回ジャンプできる。はねが続いている間に通る場所に、2段ジャンプでないと届かない
    高いどんぐりを置く（ふつうのジャンプで届くのは地面から約230まで。高いどんぐりは290〜305の高さ）
  - ほし：取ると8秒の間キラキラ光り、障害物にぶつかっても平気
  - パワーアップ中は、画面の右はしに残り時間がバーで出る（残りが少なくなると、やさしく点滅）
- 障害物：低い石・池（こい青で、ふちに明るい線）・高い切り株
- ステージ1〜5（のはら・おはなばたけ・もりの みち・かわべ・ゆうやけ）。始まるときに「ステージ3」のように大きく表示。
  1ステージは「ふつう」で約55秒。ならびは毎回同じ。ステージが進むほど、少しずつ はっきり むずかしくなる

  | | ステージ1 | 2 | 3 | 4 | 5 |
  | --- | --- | --- | --- | --- | --- |
  | 走る速さ（ステージ1を1） | 1 | 1.1 | 1.21 | 1.33 | 1.46 |
  | 障害物の数（ふつう） | 12 | 16 | 20 | 25 | 30 |
  | 障害物の種類 | 低い石だけ | ＋池 | ＋高い切り株 | ＋2つ続けて来る | 全部が混ざる（2つ続けても多め） |
  | 池の幅 | − | 64 | 74 | 84 | 94 |
  | はね・ほし | 2・2 | 2・1 | 1・1 | 1・1 | 1・0 |

- むずかしさ（どれでも、ステージが進むほど むずかしくなる しくみは同じ）
  - **やさしい**：全体がゆっくり（約0.75倍）。障害物は少なめ（約0.75倍）。ぶつかっても少し前に戻ってやり直す
  - **ふつう**：ぶつかっても少し前に戻ってやり直す
  - **むずかしい**：速さ約1.1倍、障害物 約1.2倍。画面の上にハート3つの体力ゲージが出て、ぶつかるたびに1つ減る。
    3回ぶつかると「おしまい」（それまでの どんぐりの数と「もういちど」「もくじ」）。ほしを取っている間は減らない
- ぶつかったとき：「おっとっと」と出て、やさしい「ぽよん」という音のあと、少し前の場所に戻って、すぐ続きから走り出す。
  同じ障害物に3回ぶつかったら、そこはひよこが自分でジャンプして手伝う（やさしい・ふつう）
- ゴールすると、はなまると取ったどんぐりの数を表示。「つぎの ステージ」「もういちど」「ステージを えらぶ」
- ランキング：はじめに なまえ（イニシャルと色のマーク）を選ぶ。ゴールしたら「きろくを おくる」で QRコードを出せる
  （「ランキング」を見てください）
- クリアしたステージは この iPad の中（ブラウザの保存領域）に保存し、ステージ選びの画面で次のステージがひらく
  （クリアしたステージには はなまると、いちばん多く取ったどんぐりの数）。外部には何も送りません
- 音：ジャンプ・どんぐり・パワーアップ・ゴールの効果音（ひかえめな音量）。「おと」ボタンでオン・オフ。
  こえで あそぶ ときは、効果音をマイクが拾ってジャンプしないように、大きめの音のあと少しの間は声に反応しない
- 「もくじ」ボタン：遊んでいる最中に押すと一時停止して「やめる？」と出る（「つづける」「ステージを えらぶ」「やめる」）。
  ほかのアプリに切り替えたときや、縦向きにしたときも一時停止します
- 先生用：ステージ選びの画面の右上の小さな「せってい」ボタンを **1秒ながおし** すると開く
  - 「こえで あそぶ」：ジャンプの待ち時間・いまの しきい値・こえテスト
  - 「ぜんぶの ステージを ひらく」：クリアしていないステージも選べる（もう一度押すと元に戻す）
  - 「きろくを けす」を2回おすと、クリアの記録とどんぐりの数を消す
- iPad の横向きで画面いっぱいに表示。縦向きのときは「よこに してね」と表示します
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

## たべもの キャッチ
上から落ちてくる食べものを、かごを持ったひよこを左右に動かしてキャッチするゲームです。開くときにパスワードがいります。

- 操作：画面を指で左右になぞると、ひよこが指についてくる。左右の下のすみの「＜」「＞」ボタン（おしている間 動く）でも動かせる
- 落ちてくるもの（でてくる回数は、得点が高いものほど少ない）
  - チーズ 10てん・かんぴょう 20てん・ラーメン 30てん・ぎょうざ 40てん・いちご 50てん
  - ハート：体力が1つ回復（体力がへっているときだけ、たまに出る）
  - かみなり・いわ・さる：キャッチすると体力が1つへる
  - 絵は絵文字。かんぴょうは合う絵文字がないので、干したかんぴょうの束（クリーム色の帯を束ねて ひもで しばった形）を
    プログラムで描き、下に小さく「かんぴょう」と書く
  - 見やすさ：落ちてくる物は、白くて太い ふちどりの丸の上にのせて目立たせる。体力がへるものは、ふちどりを こい灰色にして
    見分けやすくする。背景は、落ちてくる物が目立つように、少し暗めの落ち着いた色。落ちるときは ほぼ まっすぐ（文字が さかさに ならない）
  - 落ちる場所の地面に かげが出るので、どこに落ちるか分かる
- 体力：画面の上にハート3つ。へったハートは うすい色になる
  - よけるものに当たると、ひよこが目をつぶって少しゆらゆらし「おっとっと」と出る（やさしい「ぽよん」の音）。
    ゆらゆらしている約1秒の間は、よけるものに当たってもはじくだけで、体力はへらない
  - はじめの3秒は、よけるものは出ない
- 体力が0になったら「おしまい」。得点とハイスコアを表示し、「もういちど」「もくじ」を選べる
- ランキング：はじめに なまえ（イニシャルと色のマーク）を選ぶ。「おしまい」で「きろくを おくる」を押すと QRコードを出せる
  （「ランキング」を見てください）
- むずかしさ：30秒ごとに「レベルアップ」と小さく表示し、落ちる速さと数が少しずつふえる（レベル11で頭打ち）
- はやさ：はじめの画面で「ゆっくり」「ふつう」を選ぶ（最後に選んだものを覚えています）
- ハイスコア：上位5つを日付といっしょに この iPad の中（ブラウザの保存領域）に保存（名前は入れない。外部には何も送りません）。
  はじめの画面と「おしまい」の画面に表示。いちばんの記録をこえたら「しんきろく！」と表示
- 音：キャッチ・ダメージ・レベルアップ・おしまいの効果音（ひかえめな音量）。「おと」ボタンでオン・オフ
- 「もくじ」ボタン：遊んでいる最中に押すと一時停止して「やめる？」と出る（「つづける」「はじめの がめん」「やめる」）。
  ほかのアプリに切り替えたときや、iPad の向きを変えたときも一時停止します
- 先生用：はじめの画面の右上の小さな「せってい」ボタンを **1秒ながおし** すると開く。
  ハイスコアの一覧（日付・はやさつき）を見られ、「ハイスコアを けす」を2回おすと消える
- iPad の縦向き・横向きどちらでも遊べる
- 絵も音もページの中で作るので、画像や音のファイルは不要。オフラインでも使えます

### こえで あそぶ（声の大きさだけで遊ぶモード）
手足が思うように動かない子が、声だけで遊べるモードです。言葉の聞き取り（音声認識）は使わず、マイクの **声の大きさ** だけを見ます。
録音・保存はせず、どこにも送りません。オフラインでも動きます。

- はじめの画面で「ゆびで あそぶ」「こえで あそぶ」を選ぶ（最後に選んだものを覚えています）
- ひよこの場所は左・右の2つだけ（地面にうすい丸の しるし）。声を出すたびに左右が入れかわる
- 食べものなどは、左か右の列の上から落ちてくる（同じ列が3回より多く続かない）
- 落ちる速さは、とてもゆっくりから始まり、レベルアップしても ゆるやかにしか速くならない。
  最初の速さは「せってい」で「とても ゆっくり」「ゆっくり」「すこし ゆっくり」から選ぶ
- 1回入れかわったら、1秒は次の声に反応しない（声がのびても1回だけ。待ち時間は「せってい」で 0.7〜2秒に変えられる）。
  声が1度 線より下に下がってからでないと、次は反応しません
- ドアの音などの短い物音（0.08秒より短い音）には反応しない。ゲームの効果音が鳴った直後も、少しの間 反応しない
- 遊んでいる間は、画面の下に声の大きさのメーターと、反応する線を表示
- 「おしまい」のあと約2.5秒たつと「こえを だすと、もういちど あそべるよ」と出て、声で もう一度 遊べる
- 画面のタップや、スペース・エンターキー（外づけのスイッチなど）でも入れかわる（手伝う人や、スイッチを使う子のため）
- ハイスコアは「ゆび」と「こえ」で べつべつに上位5つ
- **こえテスト**：はじめの画面の「こえテスト」で、声の大きさのメーターと、反応する線を表示。
  「おおきく ▲」「ちいさく ▼」で線を動かして調整（病室の物音で動くときは「おおきく」）。
  調整した値は この iPad の中に保存され、声で遊ぶ ほかの教材とも共通です
- **マイクの許可**：マイクを使う前に、なぜ使うのかを やさしく表示してから、iPad の許可の確認を出します。
  許可しなかったときは「せってい」→「Safari」→「マイク」で許可できます、と表示します
- ほかのアプリに切り替えたときはマイクを止め、「つづける」を押すと また使います
- マイクを使っている間は、iPad の効果音が小さめに聞こえることがあります（iPad のしくみ）

### めで あそぶ（iPadの きのう）
目の動き（視線）で遊ぶモードです。iPad の「視線トラッキング」（iPadOS 18 以降。「設定」→「アクセシビリティ」→「視線トラッキング」）を
オンにして使います。指でタップしても遊べます。視線トラッキングに対応していない iPad（第8世代など）では、
次の「めで あそぶ（カメラ）」を使ってください。

- はじめの画面で「めで あそぶ（iPadの きのう）」を選ぶ
- ひよこの場所は左・右の2つだけ。行きたいほうを じっと見つめる（約0.6秒）と、ひよこが そちらへ動く。
  見つめている間は、ひよこの上の あたりに 丸い わが たまっていく
  - 視線トラッキングの「見つめてタップ（滞留コントロール）」で画面がタップされたときや、指でタップしたときは、タップしたほうへ すぐ動く
  - 左右の矢印キーでも動く
- 落ちてくる物は ほかのモードの3倍、ひよこは約1.5倍の大きさ。大きくしても、左右2列の物や ひよこが となりの列と重ならないように はなして並べる。
  同じ列で 物どうしが たてに重ならないように、上の ほうが あいてから 次の物を出す
- 落ちる速さ・数の増え方は「こえで あそぶ」と同じ（とても ゆっくり から始まり、速くなるのも ゆるやか）。
  最初の速さは「せってい」の「こえで あそぶ・めで あそぶ」で選ぶ（「めで あそぶ（カメラ）」も同じ）
- ハイスコアは「め」だけで べつに上位5つ
- 見つめているだけで動くのは、視線トラッキングのポインタが画面の上を動いているとき（ページに ポインタの位置が伝わるとき）です。
  伝わらない設定のときも、見つめてタップ（滞留コントロール）で動かせます

### めで あそぶ（カメラ）
iPad の まえの カメラ（インカメラ）の映像から、ページの中で 黒目の位置と 顔の向きを読み取って遊ぶモードです。
iPad の視線トラッキング機能を使わないので、**iPad 第8世代** など 視線トラッキングに対応していない iPad でも遊べます。
読み取りには MediaPipe の Face Landmarker を使います（`shared/mediapipe/`。外部からは読み込みません）。

- はじめの画面で「めで あそぶ（カメラ）」を選ぶ
- **カメラの許可**：カメラを使う前に、なぜ使うのかを やさしく表示してから、iPad の許可の確認を出します
- **めの じゅんび（キャリブレーション）**：ゲームの前に、画面の 左・まんなか・右 に順番に丸が出て、
  「ここを みてね」と読み上げる（音が「おと なし」のときは読み上げない）。丸が動いてから 2秒、丸を見てもらう（丸の まわりの わが たまっていく）
  - その結果から、その子の「ひだり」「まんなか」「みぎ」を決める。結果は この iPad に保存し、次からは「まえと おなじ」でとばせる
  - 顔が見えなかったり、左右の ちがいが わからなかったりしたときは「うまく いかなかったよ」と出て、「もういちど」でやり直せる
- ゲームでは、ひよこの場所は左右2列。左を見ると左、右を見ると右に動き、まんなかを見ているときは その場にとどまる
  - ちらっと見ただけで動かないように、同じほうを **0.5秒** 見続けたら動く（見ている間は わが たまっていく）。「せってい」で 0.3〜1.5秒に変えられる
- 判定に使うもの：「せってい」で「め」（黒目の位置）・「かお」（顔を すこし左右に向ける）・「りょうほう」（大きく動いたほう）から選ぶ。はじめは「りょうほう」
- 落ちてくる物は 3倍、ひよこは 約1.5倍。落ちる速さは「こえで あそぶ」と同じく とても ゆっくり から始まる（最初の速さは「せってい」）
- 顔が見つからないときは「かおが みえないよ」、部屋が暗くて読み取れないときは「へやを あかるくしてね」と出して、ゲームを止めて待つ（顔が見えたら そのまま続く）
- **しせんテスト**：はじめの画面の「しせんテスト」で、いま「ひだり」「まんなか」「みぎ」のどれと判定しているかを大きく表示する。
  「カメラの えいぞう：だす／ださない」で、カメラの映像を小さく出すかを切り替えられる（ゲーム中も 下に小さく出る）。「あわせなおす」で キャリブレーションをやり直せる
- ハイスコアは「カメラ」だけで べつに上位5つ
- **プライバシー**：カメラの映像は この iPad の ページの中だけで処理し、保存も送信もしません（録画もしません）。
  保存するのは、キャリブレーションの結果（数字だけ）と せっていだけです
- **軽く動かす工夫**（第8世代でも ゲームがカクカクしないように）：カメラの映像は 320×240 くらいの小さな解像度で読み取り、
  判定は 1秒に15回まで。使えるときは GPU で計算する（使えないときは CPU）。部屋の明るさは 1秒に1回、とても小さくした画像で調べる
- **オフライン**：MediaPipe のファイル（ぜんぶで 約25MB）は、はじめて「めで あそぶ（カメラ）」を使ったときに
  `sw.js` が まとめて保存します。そのあとは オフラインでも使えます。**はじめての1回は、インターネットにつながった ところで** 使ってください
  （大きいので、教材の版を上げても 取り直さないように、べつの保存場所 `kyozai-shisen-…` に入れています）

## しせん（共通の部品 `shared/shisen.js`）
カメラの映像から「ひだり」「まんなか」「みぎ」の どれを見ているかを判定する部品です。ほかの教材でも使えます。

```html
<script src="../shared/shisen.js"></script>
```
```js
var eye = Shisen.create({
  onDir: function (dir) { /* 'left' / 'center' / 'right' / null（顔が見えない） */ },
  onStatus: function (st) { /* 'loading' / 'ok' / 'noface' / 'dark' */ }
});
// ボタンを押したとき：なぜカメラを使うかを見せてから、許可 → 読み込み
Shisen.explain({ eye: eye, onOk: function () {
  Shisen.calibrate(eye, { onDone: function () { /* ゲームを はじめる */ } });  // 「まえと おなじ」も えらべる
} });
eye.stop();   // 使い終わったら カメラを止める
```

| 名前 | 内容 |
| --- | --- |
| `Shisen.create(設定)` | センサーを作る（カメラはまだ使わない）。`onDir`・`onStatus`・`source`（`'eye'`／`'face'`／`'both'`） |
| `eye.start()` / `eye.stop()` | カメラと MediaPipe を使い始める（Promise）／止める |
| `eye.getDir()` / `eye.getStatus()` / `eye.getScore()` | いまの判定／ようす／-1（ひだり）〜+1（みぎ）の値 |
| `eye.setSource(…)` / `eye.setCalib(…)` | 判定に使うもの／キャリブレーションの結果を変える |
| `eye.showPreview(要素 または null)` | カメラの映像を その要素の中に（左右反転して）出す／かくす |
| `Shisen.explain({ eye, onOk, onCancel })` | カメラを使う前の説明 → 許可 → 読み込み（読み込み中は「じゅんびしています…」） |
| `Shisen.calibrate(eye, { onDone, onCancel, speak, askSame })` | キャリブレーション（左・まんなか・右を2秒ずつ）。`askSame: false` で「まえと おなじ」をきかない |
| `Shisen.openTest(eye, { onClose })` | しせんテストの画面 |
| `Shisen.loadSettings()` / `Shisen.saveSettings({ source, dwell, preview })` | せってい（保存名 `shisen-v1`。全教材で共通） |
| `Shisen.loadCalib()` / `Shisen.saveCalib(…)` | キャリブレーションの結果（保存名 `shisen-calib-v1`） |

- 判定のしくみ：顔の点から「黒目が 目じりと目がしらの間の どこにあるか」と「鼻の先が 左右のほおの間の どこにあるか」を数にし、
  キャリブレーションで はかった 左・まんなか・右の値と くらべる。左右の値の半分より外に出たら「ひだり」「みぎ」、
  もどるときは もう少し内側まで もどったら「まんなか」（ゆれで いったりきたり しないように）
- 使う教材は `sw.js` の `ASSETS` に `./shared/shisen.js` を入れてください（`shared/mediapipe/` は `SHISEN_ASSETS` で別に保存します）

## こえスイッチ（共通の部品 `shared/koe-switch.js`）
マイクの声の大きさで「スイッチを押した」ことにする部品です。ほかの教材でも使えます。
言葉の聞き取りはせず、録音・保存も、外部への送信もしません（ページの中で大きさを計算するだけ）。

### 使い方
```html
<script src="../shared/koe-switch.js"></script>
<script src="./mykyozai.js"></script>
```
```js
var conf = KoeSwitch.loadSettings();      // この iPad に保存した しきい値・待ち時間（全教材で共通）
var sw = KoeSwitch.create({
  threshold: conf.threshold,              // 0〜1。この大きさを こえた声で反応（ふつう 0.5）
  cooldown: conf.cooldown,                // 反応したあと、次に反応するまでの ミリ秒（ふつう 1000）
  onTrigger: function () { /* 声でスイッチが押されたとき */ },
  onLevel: function (level, threshold) { /* 毎こま。メーター用（level は 0〜1） */ }
});

// ボタンを押したとき（タップの中）に start を呼ぶ。iPad ではタップの中でないと動きません
button.addEventListener('click', function () {
  sw.start().catch(function (err) { alert(KoeSwitch.errorMessage(err)); });
});
sw.stop();   // マイクを止める（使い終わったら・ほかの画面に移るとき）
```

| 名前 | 内容 |
| --- | --- |
| `KoeSwitch.create(設定)` | スイッチを作る。設定は `threshold`・`cooldown`・`minDuration`（この ミリ秒以上 続いた声だけ反応。ふつう 80）・`needQuiet`（1度 線より下に下がるまで次は反応しない。ふつう true）・`onTrigger`・`onLevel`・`onStop`（マイクが止められたとき） |
| `sw.start()` / `sw.stop()` | マイクを使い始める（Promise を返す）／止める |
| `sw.enabled` | `false` の間は、大きさは はかるが反応しない（一時停止中など） |
| `sw.setThreshold(0〜1)` / `sw.getThreshold()` | 反応する大きさ（しきい値） |
| `sw.setCooldown(ミリ秒)` / `sw.getCooldown()` | 反応したあとの待ち時間 |
| `sw.ignoreFor(ミリ秒)` | しばらく反応しない（教材が自分で効果音を鳴らすとき、マイクが それを拾わないように） |
| `sw.getLevel()` / `sw.isRunning()` | いまの大きさ（0〜1）／マイクを使っているか |
| `KoeSwitch.loadSettings()` / `KoeSwitch.saveSettings({ threshold, cooldown })` | しきい値・待ち時間を この iPad に保存・読み込み（保存名 `koe-switch-v1`。全教材で共通） |
| `KoeSwitch.errorMessage(err)` | マイクが使えなかったときの、やさしい説明の文 |
| `KoeSwitch.isSupported()` | この ブラウザで使えるか |

- 大きさは、マイクの音の強さ（-60dB〜-6dB）を 0〜1 にしたものです
- マイクの許可は https のページでだけ求められます（公開URL は https なので大丈夫です）
- マイクを使う前に、なぜ使うのかを画面に やさしく表示してから `start()` を呼んでください（「たべもの キャッチ」の `micAsk` が例です）
- 使う教材は、`sw.js` の `ASSETS` に `./shared/koe-switch.js` が入っていることを確認してください

## ランキング（きろくを あつめる）
ぴよぴよ ラン・たべもの キャッチ・しんけいすいじゃく の記録を、複数の iPad から1台に集めてランキングにします。
**ネットは使わず**、QRコードで記録をわたします。

### こどもの iPad（ゲーム）
- **なまえ（イニシャル）**：ゲームを始める前に、アルファベット2文字（例：T.K）を大きなボタンで選ぶ。
  同じイニシャルの子を見分けられるように、**色のマーク**も8種類から1つ選ぶ
  （あか・まる／オレンジ・さんかく／きいろ・ほし／みどり・しかく／みずいろ・ひしがた／あお・ハート／むらさき・じゅうじ／ピンク・しずく。
  色が見分けにくい子でも分かるように、形も変えています）
- 選んだイニシャルと色は その iPad に保存し、次からは聞かない。はじめの画面の「T.K ● なまえを かえる」を押すと変えられる
  （ぴよぴよ ラン：画面の上／たべもの キャッチ：スタートの上／しんけいすいじゃく：「はじめる」の上。ふたりで遊ぶときは出ない）
- ゲームが終わったら「**きろくを おくる**」ボタンが出る。押すと記録の QRコードを大きく表示する
  - ぴよぴよ ラン：ゴールしたとき（むずかしい で「おしまい」になったときは出ない）。どんぐりの数・むずかしさ・ステージ
  - たべもの キャッチ：「おしまい」のとき。点数と、あそびかた・はやさ（ゆび・ふつう など）
  - しんけいすいじゃく：ひとりで全部そろえたとき。めくった回数と時間・むずかしさ
- QRコードの中身：ゲームの名前・むずかしさ（・ステージ）・点数（または どんぐりの数、めくった回数と時間）・イニシャル・色・日時・
  記録ごとの しるし（同じ記録を2回読んでも重ならないように）。名前（フルネーム）や顔などは入りません

### あつめる係の iPad（先生用）
- メニューの右上の「せってい」を **1秒ながおし** →「**ランキングを あつめる**」
- 「QRコードを よみとる」：カメラで こどもの iPad の QRコードを写すと、記録が追加される。
  読み取ると「T.K さんの きろくを うけとったよ」と表示（小さな音も鳴る）。右に、受け取った記録の一覧が出る
  - 「インカメラに する」「そとの カメラに する」で切り替え（最後に使ったほうを覚えています）
  - 同じ QRコードを2回読んでも重ならない（「もう うけとって いるよ」と出る）。記録以外の QRコードは「きろくでは ないよ」
  - **カメラの映像は保存も送信もしません**（QRコードを読むために1枚ずつ見て、すぐ捨てます）。「おわる」でカメラを止める。
    ほかのアプリに切り替えたときも止めます
  - はじめて使うときは、iPad がカメラの許可を聞きます。「許可」を押してください
- ランキング：ゲームごと・むずかしさごと（ぴよぴよ ランは ステージごとも）に、上位10位までをイニシャルと色のマークで大きく表示。
  横向きは5位ずつ2列、縦向きは1列
  - 「きょう」「ぜんぶ」で切り替え（「ぜんぶ」のときは日付も出る）
  - 並べかた：ぴよぴよ ラン・たべもの キャッチは数が多いほど上。しんけいすいじゃくは めくった回数が少ないほど上
    （同じ回数なら時間が短いほう）。点数が同じなら同じ順位
  - 同じ子（イニシャルと色が同じ）は、いちばん良い記録だけを出す
  - むずかしさのボタンは、記録があるものだけ出る
- 保存：ランキングは この iPad の中（ブラウザの保存領域）に保存。外部には何も送りません
- 「**かきだす**」：ランキングを CSV ファイル（`ranking-年-月-日.csv`）に保存。iPad では共有の画面が出るので
  「"ファイル" に保存」を選ぶ。Excel・Numbers でも開けます（列：id・game・game_name・diff・diff_name・stage・score・
  time_ms・initials・color・color_name・played_at・played_at_ms）
- 「**よみこむ**」：書き出した CSV を読み込んで元に戻す（今ある記録に足す。同じ記録は重ならない）
- 「**ぜんぶ けす**」：2回確認してから、集めた記録を全部消す
- オフラインでも使えます

## ゲームの パスワード
授業中に子どもが かってにゲームを開かないように、ゲーム（ぴよぴよ ラン・たべもの キャッチ）は
数字4けたのパスワードを入れないと遊べません。

- メニューでゲームのボタンを押すと、パスワードの画面が出る（ボタンに「パスワード」と かぎの しるし）
  - 大きな数字ボタンで入れる。入れた数字は ● で かくれる。「けす」で1つ、「ぜんぶ けす」で全部消す
  - 正しければゲームが開く。まちがえたら「ちがうよ。もういちど いれてね」と出る
- 一度開いたら、ゲームを終えてメニューに戻るまでは聞かない（ゲームの中で「もういちど」やページの再読み込みをしても聞かない）
- メニューを通らずに ゲームのページを直接開いたときや、「もどる」で ゲームに戻ったときも、パスワードを聞く
- はじめのパスワードは **0000**
- **パスワードを変える**：メニューの右上の小さな「せってい」ボタンを **1秒ながおし** →「ゲームの パスワードを かえる」→
  いまのパスワード → 新しいパスワード → もう一度 新しいパスワード（1回目と ちがうときは、新しいパスワードから やりなおし）
- 変えたパスワードは この iPad の中（ブラウザの保存領域）にだけ保存し、プログラムの中には書きません。
  保存するのは数字そのものではなく、そこから計算した値です。ほかの iPad には うつりません
- オフラインでも使えます
- 子どもが かってに開かないための しくみです。大事な情報を守るための かぎ ではありません

### パスワードを わすれたとき
この iPad に保存したサイトのデータを消すと、パスワードは **0000** に戻ります。

- **Safari で開いているとき**：iPad の「設定」→「アプリ」→「Safari」→「詳細」→「Webサイトデータ」で、
  `tomo76922.github.io` を左にスワイプして「削除」する（iPadOS 17 までは「設定」→「Safari」→「詳細」→「Webサイトデータ」）
- **ホーム画面に追加して使っているとき**：ホーム画面のアイコンは Safari とは べつにデータを持っています。
  上の方法で戻らないときは、ホーム画面のアイコンを長押しして削除し、Safari で公開URLを開いて もう一度「ホーム画面に追加」する
- 消すと、ゲームの記録（クリアしたステージ・どんぐり・ハイスコア）や、はやさ・音・こえテストの設定、
  ランキング用の なまえ、集めたランキングも消えます（ランキングは先に「かきだす」で保存しておいてください）
- オフライン用の保存も消えるので、消したあとは一度 ネットにつながった状態でメニューを開いてください

### 共通の部品 `shared/game-lock.js`（ゲームを ふやすとき）
- ゲームのページ：`<body>` の すぐ あとに `<script src="../shared/game-lock.js" data-guard="ゲームの名前"></script>` を書く
  （メニューでパスワードを入れて開いていなければ、ページを開いたときに聞く）
- メニュー：ゲームの `<a class="menu-item">` に `data-lock="ゲームの名前"`（`data-guard` と同じ）と
  `data-lock-name="画面に出す名前"` を つける（`menu.js` が `GameLock.bindMenu()` で聞く）
- そのほか：`GameLock.ask({ onOk })`（パスワードを聞く）、`GameLock.change()`（パスワードを変える画面）、
  `GameLock.check('1234')`（正しいか）

## iPad での使い方
1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」でアプリのように使えます
3. 音が出ないときは、本体の音量・消音モード（サイレント）を確認してください。

## 教材をふやすとき
1. 新しいフォルダ（例：`tokei/`）を作り、`index.html` などを置く
   - `<head>` で `../manifest.webmanifest` と `../common.css` を読み込む
   - 画面に「もくじ」ボタン（`<a class="home-btn" href="../">`）を置く
   - 最後に `<script src="../pwa.js"></script>` を読み込む
2. メニュー（`index.html`）に `<a class="menu-item">` を1つ足す
   - ゲームのときは、パスワードを聞くようにする（「ゲームの パスワード」の「共通の部品」を見てください）
3. `sw.js` の `ASSETS` に新しいファイルを足し、`CACHE_VERSION` を上げる
4. `news.json` に「新しく 追加しました」の おしらせを1件足す

## 更新するとき
ファイルを変更したら `sw.js` の `CACHE_VERSION`（例：`v5` → `v6`）を上げてください。
あわせて `news.json` に おしらせを1件足してください（「おしらせ」を見てください）。
（`shared/mediapipe/` の ファイルは べつで、入れかえたときだけ `SHISEN_CACHE` の名前を変えます）

- ネットにつながっているときは、いつも最新のファイルを読み込みます。
  つながっていないときだけ、保存してある版を表示します。
- 新しい版に切り替わると、ページが自動で1回だけ再読み込みされます
  （タイマーが動いている間は再読み込みしません）。
